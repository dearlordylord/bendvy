# FailedTxn Motion64 comparative adapter

This leaf separates verification and private diagnostics from the accepted semantic consumer. Motion64 JS, Native and TS now pass their complete independently derived semantic wires. No comparative cohort is qualified. The accepted consumer, method, reference, models and shared ECS source remain unchanged.

The adapter imports the original `motion-callbacks.bend` and `motion-grants.bend` directly. Their business body, operations and declarations are unchanged. Local/Reader/Dispose specializations omit the private TxFacts field and observer capability entirely. They preserve transaction begin/finish, rollback, the actual output/error variants, rejected affine payloads, Local capture increments, reader prepare/commit/release and cursor deltas. The existing registration sequence, nine adoption factories, owner tree, phase predicates, App validation/replanning, barriers and public reads remain reached.

The first original boundary query and Main lookups produce detached full `PublicBoundary` records. The existing repeated common-capture queries remain separate and produce the exact original 965-record common carrier. Public App.describe results remain actual schedule records. Before clock end the adapter materializes, encodes and folds both complete carriers and accepts FORCE and PUBLIC-FORCE output. After end it writes complete TUPLE, PUBLIC-TUPLE and ACTORS lines. It creates a fresh warmup world, completes its transport, then creates a fresh sample world.

Bend's supplemental record is `{boundaries:[PublicBoundary],schedules:[Schedule],calls:[DisposePublic]}`. Each of the 256 boundaries retains iteration, phase, all ordered rows, pendingA, latestFailed, retryB and allFailed with actual access variants and full returned fields. Each of the 385 actual schedule results retains namespace, name, ordered steps, requirements, failure and observations. The 64 DisposePublic records retain the actual returned command statuses and transaction outcome. Private world/allocator/queue/owner snapshots are absent, including their capture work.

TS's supplemental record is `{callbacks:[CallbackPublic],publications:[PublicationsPublic],boundaries:[PublicBoundary]}`. It retains the first lagged read and two post-write readbacks formerly used by B assertions, the first publication all/lagged reads, every successful lookup's full projected row, and all three actual boundary Ledger reads. It adds no queries to mimic Bend. The runtime debug listener remains only where it supplies actual common outcome/error values. Expected-state construction, independent assertions, private frame/tick/missed diagnostics and diagnostic SHA work are absent. Original outcome/error guards that control abort or continuation, including intended B failure classification, remain. Identity/encoding guards and source-pin checks also remain. These supplemental carriers have separate role gold because the original public read strategies differ.

Independent source-derived gold must reproduce the unchanged common carrier first, then derive both full supplemental carriers from the existing operation model and actual source calls. Source checks use pinned private Bend2.0.35 resources and Node24. No runtime launch is authorized by this README. Clock units, seven rotations, reset child RSS, numerical decision margins and final performance gates retain their existing separate qualification requirements.

The first semantic results are retained temporarily at `/tmp/bendvy21-failedtxn-motion-comparative-normal-actual01/`: each role has its frozen plan, complete collector receipt, `RESULT.json` and raw clock identities. The joined packet is `/tmp/bendvy21-failedtxn-motion-comparative-normal-actual01/JOINED.json`. Bend JS/Native each match 61,433,187 bytes; TS matches 47,654,772 bytes. Both worlds retain 965 common records (3,504,864 cells); complete role-public carriers are independently checked as well. The source-derived model and preservation checks are runnable through `model/seal_gold.py`. These results establish semantic correspondence, not clock accuracy, RSS or comparative performance. Health, wider inputs and comparative cohorts remain unqualified.
