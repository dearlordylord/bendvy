# GH82 generalized sparse storage foundation

These are focused source consumers for reusable framework modules, based on private full-WC stage `58866f54ba1e455a9d43e3ac75a4042bd7af387f`. They do not supply ordinary Builder/Prepared integration, backend observations, law proofs, native worker qualification or complete GH82 acceptance.

| Module | Interface and responsibility |
| --- | --- |
| `execution-query-domain.bend` | Dynamic physical offset lists; duplicate/range validation, set union, and per-family read/write conflicts. Overlapping reads are compatible; any overlapping write conflicts. These offsets are not entity identities. |
| `chunk-partition.bend` | `cut(S,C,column,left,right)` first validates the complete balanced tree, both leaf arrays, complete domains and overlap. It then moves actual optional affine cells and stamps into sparse slices, retaining the complement and affine `JoinOwner`. Tree traversal is structural, with no tree-depth fuel or finite mask/family universe. Leaf width remains the existing Column contract of eight cells. |
| `chunk-partition.bend` | `join` validates returned domain declarations, actual unique cell offsets and original shape before insertion. Refusal retains complement, both slices and join owner. Successful insertion returns every displaced actual cell, including its prior stamp; unexpected occupied cells are not discarded. |
| `execution-query-slice.bend` | `Slot` carries schema S and full `Layout.origin` (P, V, refresher, key and persistence class). `cut` accepts the corresponding actual full-layout `ColumnSlot`. The branded affine join owner and returned column retain that origin. Sparse storage is never equated with full WC. Cached reads do not invoke an affine projector. Editing refreshes the retained cache and stamp; denied/absent edits return the exact unused transform. |
| `execution-query-matches.bend` | A closed per-family `Recipe` derives both read/write capabilities and all-grant access domains. `prepare` validates every original grant before union. `query` recomputes value predicates from retained current caches each call and checks the entire requested domain before selection; it does not truncate requests to the owned slice. Required/optional/With/Without inspect actual optional storage. Explicit `ReadCache` capture yields reusable branded Data observations. |

The physical and slice modules are trusted framework layers. Public raw constructors and internal helpers are not claimed to enforce language-wide secrecy. Gameplay must eventually receive rank-2 abstract H operations from the ordinary closed interpreter. In particular, a caller cannot gain entity authority merely by constructing one of these numeric domains.

`positive.bend` instantiates two nominal schemas with genuinely different full layout shapes, an actual four-leaf Position tree and a two-leaf Shield tree. Position owns an Array; Shield owns String plus a differently sized Array. The same-leaf interleaving and cross-leaf cuts retain actual absent cells as well as present owners. The Position consumer writes 0/8 and 1/9 through a native `l r` binding, retains left BodyError and right Success, and rejoins before returning both Local owners, cache observations, tick/prior and the complete restoration/displaced inventory. Source checking this binding is not evidence of backend concurrency or evaluated values.

Other consumers exercise original-owner refusal for duplicate/overlap/out-of-bounds domains and malformed branches/leaf arrays; malformed returned slice inventory; a U32-max operation returning its unused affine transform; unlike-payload edits; a fresh query after own write; optional absent membership; reusable read-cache Data; all-grant broad-writer conflict; and broad query requests that cannot silently truncate. Numeric refusals are source-valid result paths, not compile-time-rejection claims.

Six `reject-*.bend` files reach intended type/affine boundaries: duplicate slice use, read capability passed to write, unlike nominal schema, genuinely different full schema shape, unlike full origin, and generic H duplication while returning H. The last is an affine confinement control, not proof that the future ordinary interpreter is rank-2 confined. Raw diagnostic files and a source-bound receipt are retained at `/tmp/bendvy-gh82-general-storage/.audit/gh82-general-storage/`.

The behavior references are pinned Bevy [With](https://github.com/bevyengine/bevy/blob/ad678262ce53b5d142fe49ee5e08caff6f00ab60/crates/bevy_ecs/src/query/filter.rs#L199), [Without](https://github.com/bevyengine/bevy/blob/ad678262ce53b5d142fe49ee5e08caff6f00ab60/crates/bevy_ecs/src/query/filter.rs#L314), [optional fetch](https://github.com/bevyengine/bevy/blob/ad678262ce53b5d142fe49ee5e08caff6f00ab60/crates/bevy_ecs/src/query/fetch.rs#L3254), and [mutable batch duplicate admission](https://github.com/bevyengine/bevy/blob/ad678262ce53b5d142fe49ee5e08caff6f00ab60/crates/bevy_ecs/src/system/query.rs#L2098). Physical affine scatter/rejoin, cached-view refresh and dynamic invocation-domain checking are Bend-specific mechanisms; Bevy links do not establish their correctness.

## Next integration interfaces and remaining work

The full-schema interpreter must traverse the actual full Layout and its canonical product together, using validated routes to select `ColumnSlot<S,Layout.stored(layout,route),Layout.key(layout,route),Layout.origin(layout,route)>`. It must prepare all per-family recipes, union every grant domain, account for all predicate-examined rows and structural membership dependencies, exclude conflicts, and only then cut mutable owners. Read/read sharing uses structural cached Data after admission; an overlapping live read/write remains a conflict. An explicit old cache capture cannot silently replace an ordinary live read.

That interpreter must derive stable With/Without invocation upper bounds from actual captured storage membership, independently from fresh per-operation value-predicate matches. Optional-only enumeration must use actual captured live handles, not capacity or occupied allocator slots. General multi-family query shapes, optional writes, ordinary count/single/get result contracts, sequential cross-entity algorithms, target-owned effects and schema-wide failure reconstruction still need their coordinated integration consumers.

The ordinary Builder must lower its same closed Program into these capabilities and per-family access domains. Full WC remains declaration/admission authority; sparse local H remains a different owner type. Actual Prepared namespace, complete genuine handle/generation membership, captured tick/prior, exact system Local/output/queue return and group error policy must be preserved. Full public identity is one-based; only a checked chunk adapter may convert a captured valid logical key to physical index minus one. No global `World.handle_index` change or synthesized handle from offset is supplied here.

Ordinary rank-2 escape/undeclared-access controls, two IO-created same-schema Worlds, retained body-error plus peer-success backend observations, useful native worker participation, normal repository checks and independent Spec/Standards review remain required. This phase adds no laws, compiler changes, dependencies, runners or backend artifacts.
