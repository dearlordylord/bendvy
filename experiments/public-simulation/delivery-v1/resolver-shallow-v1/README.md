The caller verifies the exact plan and actual Python bytes before importing any helper via verified source bytes. All costly resolver/resource hashing and the eight nested ldd probes are inside this cap; individual probes remain cap5. This explicitly bounds hashing rather than leaving it outside command supervision. The byte scope exceeds 3.15 GB per resolver pass plus resource checks, so completion within this cap is unestablished. A cutoff must remain INCOMPLETE; it cannot imply a larger approved limit or resolver admission.

The parent retains returned outer bytes even if Runner publication fails and hashes all actual regular partial outputs in post/final guards. Source/plan/interpreter checks remain small outside the capped worker. No compiler or runtime workload is included; an acquired snapshot itself is not delivery qualification.
