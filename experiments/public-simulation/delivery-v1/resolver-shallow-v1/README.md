# Shallow resolver input preparation

This is a metadata-only candidate for the existing `PinnedTools(resolver_inputs=..., loader_search_directories=...)` API, **not resolver admission**. `prepare.py` verifies and derives the retained v6/v5 actuals, then enumerates only immediate entries and stat sizes for the 64 candidate directories. It records cache target identities/aliases and explicit configuration/preload presence; it never recursively scans `/lib` or invokes the helper's hash/discovery stages.

The glibc 2.36 [legacy construction](https://github.com/bminor/glibc/blob/glibc-2.36/elf/dl-hwcaps.c#L158-L208) collects important capability bits, platform, then TLS. The [combination generation](https://github.com/bminor/glibc/blob/glibc-2.36/elf/dl-hwcaps.c#L272-L341) orders descending bit subsets with component strings reversed. AArch64 selects [HWCAP_ATOMICS](https://github.com/bminor/glibc/blob/glibc-2.36/sysdeps/unix/sysv/linux/aarch64/dl-procinfo.h#L26-L34), named [atomics at bit 8](https://github.com/bminor/glibc/blob/glibc-2.36/sysdeps/unix/sysv/linux/aarch64/dl-procinfo.c#L63-L67). Together with actual diagnostics (`0x100` present, `aarch64`, no built-in hwcaps), this supports the eight retained suffixes in order. This source is upstream 2.36 authority, not a byte-exact rebuild of the installed loader.

The stat inventory records **449 unique regular files / 714,937,377 bytes**. Existing shallow helper visits include aliases: **1,699 regular visits / 1,936,135,796 bytes** before additional exact-file/resource hashing. Unrelated `.a` files are included exactly as the existing policy requires. No hashing throughput or wall-time estimate is claimed. No cache target is absent among the 425 advertised entries.

A concrete shared-helper obstruction remains: **21 valid file aliases** revisit `/lib` after an absolute file link, which the existing metadata walker and `PinnedTools.chain` classify as cyclic. Example: `/lib -> usr/lib`; `/lib/aarch64-linux-gnu/libBrokenLocale.so -> /lib/aarch64-linux-gnu/libBrokenLocale.so.1`; standard path resolution yields `/usr/lib/aarch64-linux-gnu/libBrokenLocale.so.1`. Global repeated-link identity alone rejects this finite chain. The specification retains these errors, does not omit them or change the shared helper. Root must review this boundary before actual acquisition.

No uncovered directory-alias target was found by the lightweight successful chains, but failed chains remain unqualified. Cache target applicability and all shallow bytes/absence/aliases must still be admitted through existing immutable guards. Compiler header/GCC/linker and generated executable namespaces remain separate. Four portable controls cover no recursive descent, all names including archives, absent paths, broken link refusal, file-search refusal and suffix order.
