# Reusable ordinary handler Bundle interface

The missing public entry is an actual `B.Bundle` run through the ordinary generated four-phase schedule, with Bundle-wide preflight and affine selected-owner recovery. Existing `B.run` executes a monolithic handler driver; `Ordinary.run` accepts four callbacks but does not supply Bundle selection or requirement unions. The qualified private bridge binds both to fixture types and lenses.

`adapter.run` accepts closed template arguments `S, K, V, Q, C, R, E, runner, take, put, publish, same, requirement_same, has, frame`, then a runtime `Ordinary.Declaration<S>`, actual `B.Bundle`, and actual `W.World`. It returns `MarkerResult` containing the existing `B.BundleResult`, actual generated steps and actual scheduler observations. `C` and `R` remain `Type`; actual affine components/resources are never copied. `Q`, `K`, `V` and schema retain the existing public Data indices; String handler errors remain the existing H contract.

Closed callbacks are an application/provider dependency boundary, not a name-based capability grant. `take`/`put` are actual nominal slot World lenses, `publish` appends the application's actual transition event, `has` checks actual typed requirements, and `frame` performs the pre-existing marker preparation callback AFTER the ordinary Barrier. In the matched consumer frame is resource tick `Phase.tick`, not World.clock; the Barrier owns World.clock behavior. No caller-authored steps/dispatch are required.

The adapter checks Bundle namespace, collects requirements from ALL entries, stable-deduplicates using the trusted requirement comparator, and returns the unchanged Bundle/World for foreign or missing requirements before any schedule/barrier/frame. After preflight it installs the supplied ordinary declaration. Apply retains all initial entries, captures target and partitions selected owners before the exact H.prepare call. Phase failure forwards the actual phase/error and retains zipper owners; B.recover/B.recovered restore authored entry order or preserve InternalOwnerRemainder.

The generic phase module calls the existing H.prepare/run_phase/H.committed. Exit/transition failure requeues the captured target with captured skipSame and keeps the old state; earlier system effects remain committed. Successful transition commits and publishes before enter. Enter failure forwards the committed World without restoring/requeueing it. There is no whole-marker rollback, new duplicate/initializer/retention policy, artificial Data restriction on payloads, or new law.
