# Ordinary machine transition-reader evidence

This packet retains a bounded qualification of the ordinary machine transition reader. The normal role executes the 40-action initialization/read/skip/retry timeline for two nominal schemas and passes the independent 105,004-byte oracle in JS and Native. The authority role exercises actual IO-created local and foreign Worlds, foreign refusal, failed-read retry, own disposal, and the surviving reader; its 17,347-byte oracle passes in both backends. The wrong-reader-disposal mutant passes its distinct 17,433-byte counter-oracle and differs from the normal authority oracle.

The added cold-skip role registers two readers, skips one before its first open, and then reads the still-retained `Initial` notification. It verifies the first read consumes that notification once, disposal removes only the skipped reader, and the independent survivor can still read and dispose its own stream. JS and Native both pass the source-derived 13,717-byte oracle. This finite fixture has no frame, expiry, or clear operation, so it makes no broader retention claim.

The packet retains the 35-Bend normal closure, the 38-Bend foreign closure, the 38-Bend cold-skip closure, the two namespace C/JS sidecars pinned by the foreign runtime plan, independent model inputs, source-check captures, and the positive/negative affine and cross-schema type controls. The standalone foreign-disposal source check and cold-skip source check are recorded with exit code 1 for their IO/foreign definitions; neither is described as a source-check pass. Their runtime qualifications are separately bound by passing JS and Native receipts.

This is bounded runtime and type-control evidence. It makes no performance claim and does not close the wider issue.
