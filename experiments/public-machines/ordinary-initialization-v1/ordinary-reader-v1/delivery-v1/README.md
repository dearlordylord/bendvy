# Ordinary machine transition-reader evidence

This packet retains a bounded qualification of the ordinary machine transition reader. The normal role executes the 40-action initialization/read/skip/retry timeline for two nominal schemas and passes the independent 105,004-byte oracle in both JS and Native. The authority role exercises actual IO-created local and foreign Worlds, foreign refusal, failed-read retry, own disposal, and the surviving reader; its 17,347-byte oracle passes in both backends. The wrong-reader-disposal mutant passes its distinct 17,433-byte counter-oracle and differs from the normal authority oracle.

The packet also retains the 35-Bend normal closure, the 38-Bend foreign closure, the two namespace C/JS sidecars pinned by the foreign runtime plan, independent model inputs, source-check captures, and the positive/negative affine and cross-schema type controls. The standalone foreign-disposal source check is recorded with its final exit code 1 and five IO-dependent definitions; it is not described as a source-check pass. Its runtime qualification is separately bound by the passing JS and Native receipts.

This is bounded runtime and type-control evidence. It makes no performance claim and does not close the wider issue.
