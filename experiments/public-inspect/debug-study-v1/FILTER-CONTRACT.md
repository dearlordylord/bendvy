# Detached debug filter candidate contract

Draft for independent review before runtime qualification. No full Debug format published.

Filter<S,Token> contains Maybe<List<U32>> local entity IDs, List<Token> with, Limit = BoundedDecimal{List<U32> digits} | Unbounded. Token is a closed schema-authored nominal Data sum, one constructor per declared readable component family; trusted setup maps constructors to actual typed family grants. It is neither name String nor erased ordinal. Unknown/cross-schema token is a static refusal; duplicate tokens are idempotent conjunctive requirements. No arbitrary runtime family registration is introduced. Numeric IDs are display/filter coordinates in the explicitly supplied World, never cross-world authority. Single-target get separately takes actual World.Handle<S> and rejects a foreign same-id handle with MissingEntity. No mixed-handle whitelist extension exists.

TS Runtime.ts1883–1890: omitted entities includes all; Some([]) includes none; omitted with and [] are vacuously true; all required components must be present. Iterate ascending live IDs; count every live entity before filters; limit counts accepted rows, not scanned entities.

Trusted host normalizer consumes the exact JS binary64 Number domain. Omission, NaN and +Infinity normalize to Unbounded; -Infinity, every value <=0 including -0 normalize to BoundedDecimal([]); positive finite value normalizes to its mathematical ceiling natural integer without U32/F32 truncation. Native consumes the same normalized Limit, losslessly encoded as canonical little-endian decimal digits: [] is zero, each digit0..9, most-significant nonzero digit1..9. Raw constructors are trusted setup, not a parser accepting noncanonical digits. Zero test uses []; borrow decrements the digit list only after an accepted row. There is no unary Nat, U32 counter or saturation. Finite binary64 requires at most309 decimal digits. Normalization is mathematical equivalence to the pinned loop's acceptedRows.length >= limit test, not a new rejection policy. JSON does not encode NaN/infinity: authored fixtures preserve them as tagged test inputs. Positive finite binary64 values beyond Number.MAX_SAFE_INTEGER remain exact integers represented by that Number; BigInt conversion after Math.ceil is exact, serialized as decimal text and transferred to canonical little-endian digits. No native raw Number parser is introduced.

Disabled dispatch returns (owner,Disabled) and never invokes grant/projection/filter traversal. Enabled dispatch uses Check.Frame and existing Check resource/query read grants, without Check.run or Inspector.run; output type fixed before opaque H. No third storage/engine. This is functional invocation behavior, not a zero-cost/zero-allocation performance claim. Check query enumeration projects rows before outer filtering; no claim of selective projection is made.

Successful repeated dumps return all affine store/resource/queue owners and leave clocks/readers/cursors/events/pending commands unchanged. Detached Data projection values can differ from upstream shared arbitrary JS values; approved projection contract is not cloning permission. Raw declaration constructors remain trusted.
