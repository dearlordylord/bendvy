Root integrates `src/ecs`; this directory makes no production edits. The connected study is qualified through actual IO/JS/Native and full counterfactual/authority controls. Its closed `Component/Resource/Service/Machine` enums and fixed renderer are examples, not universal public tokens or a published JSON format.

| Additive production leaf | Existing candidate | Dependency / boundary |

First patch can relocate these six pure leaves with import-name changes only. Full9 primitive TS/JS/Native and reached controls plus full2 connected DTO/owner/SP results are evidence inputs, not automatic qualification of relocated production imports. Rewire the actual connected consumer to root's reviewed draft modules, freeze the exact transitive closure, then apply affected source boundaries and complete IO/JS/Native oracles/counterfactuals. Root alone adopts, after its required unchanged regression gate/source-current join.

The authoring connection must remain one retained typed declaration deriving actual `Sys.register` name/access, provision requirements and rendered System. `definition-v2.bend` demonstrates this connection for one closed schema. Do not publish its fixture IDs/enums as generic schema authority. A production composition should specialize schema-owned nominal tokens and actual core descriptor/requirement projections, keeping the affine Registry and declaration together. Query optional components must not become mandatory provisioning requirements. Typed declaration projections must supply both registration and debug metadata; independently authored description records are insufficient.

Schedule names/placements require actual registered identity keys, preserving registry namespace and id, markers, and cursor. The existing pure `naming.bend`, `schedule-metadata.bend` and `placements.bend` drafts provide typed-key/identity traversal, including repeated references/cycles; they still need an actual registered multi-system consumer and complete independent TS comparisons. No String lookup or guessed registration ID may be substituted.

The separate qualified `skeleton.bend`/`dump.bend` slice supplies nominal detached filtering, exact decimal normalized finite limits and generic arbitrary-affine owner-returned ValueRead projection. It must retain actual Check read primitives, real Handle foreign-world refusal, disabled zero projection calls and full16 owner/cursor controls when relocated. It is not another storage engine, selective-projection performance claim, or raw native JavaScript Number parser.

Existing boundaries remain explicit: SP has no Machine requirement constructor, so machine availability cannot be aliased to Resource IDs; callable service ownership/capture belongs to #50; trace/listener and stream APIs keep their existing owning tickets. Complete #56 needs the broader condition/event/query/naming/graph authoring scenarios and dependencies, not merely adoption of these pure leaves. No new ownership rule, law, policy, dependency, numeric gate or format contract is selected here.

The generic Registered layer is a trusted schema adapter, not metadata authority derived from an opaque capability body. Public authoring must expose closed canonical factories binding one nominal Definition to actual registration, SP requirements and metadata, and qualify foreign/schema/read-through-write boundaries at those factories. Descriptive strings never grant physical access. The generic Bound record alone is not the safe end-user facade.
