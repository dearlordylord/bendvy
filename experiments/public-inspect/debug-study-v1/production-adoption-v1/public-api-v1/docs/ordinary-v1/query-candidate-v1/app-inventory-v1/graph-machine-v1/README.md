one real graph/machine world. No backend has run.

state constructors or possible transitions. Existing handler bundles separately
retain selectors, requirements and registered handler access; retaining those in
normal App construction remains a concrete additional seam, not a Bend impossibility
claim or authorization to add duplicate user metadata.
