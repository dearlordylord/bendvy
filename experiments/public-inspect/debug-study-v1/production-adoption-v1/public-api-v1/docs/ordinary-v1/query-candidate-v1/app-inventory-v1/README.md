## Remaining interface limits

Current canonical `Ordinary.Schema` retains component/resource entries only. The tested world has no relation graph or machine family. Existing `relation-types.Descriptor` has its own U32 key/name/inverse/kind; existing `Machine.Family` has a typed owner lens and name. Neither is retained by this normal App/schema declaration object. Inventing a second debug registry or mapping a machine into a different registry kind would violate #56. The remaining promotion seam is normal retention of those existing declarations once, followed by enabled-only projection. This is missing plumbing, not proof of a Bend language obstruction.

Independent full expectations, strict constructor transport, executable development, reached mutation controls, public promotion and feature-specific performance qualification are still required. Source-only source inventories contain 52 files for the full App consumer and 40 for the resource consumer. Existing accepted dump/event-reader limitations remain explicit: the earlier dump used a legacy held reader, not a bounded registered-reader runtime.
