The unchanged independent TS2 full DTO oracle is distinct from the six-line Bend control oracle: two DTOs, complete owner before/after, registration, and actual provision requirements. Normal default IO, emitted JS, and Native each produced all six lines. This is a closed fixture, not the complete public Description API or a universal claim that authored providers report truthfully.
