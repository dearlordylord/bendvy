`ordinary-app-relation.bend` binds an ordinary relation declaration to an App. The same declaration supplies inverse reads, queued relation writes and automatic built-in relation debug rows; the ordinary consumer uses the library Application/Recipe aliases and changes only the debug flag. Enabled snapshots preserve the World and owners while deriving live outgoing/incoming rows; disabled snapshots bypass observation. Queued operations retain existing transaction commit/rollback and explicit World barrier behavior. The qualified witness covers direct operations, two nominal schemas and full owner/World noninterference; registered relation schedules, stream-reader policies and the remaining issue #56 categories are separate gates. Custom presentation is an expert extension; built-in graph data needs no caller renderer.
