RuntimeApp.runtime_view returns the same application and an optional descriptive view of its retained event runtime. Enable the existing debug flag to include actual batch values, reader positions (Reader IDs), event log, and runtime counters; disabled observation returns None before projecting the World. The operation does not frame, synchronize, read events, or register readers. runtime_text_u32 provides built-in U32 presentation; the generic view supports Data events without choosing a Type-event policy.
