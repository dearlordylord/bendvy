# Ordinary machine debug bridge candidate

A single ordinary machine declaration supplies its operational transaction capability, nominal slot lens and automatic debug CurrentView/name. The enabled recipe composes with existing rows without inventing a Resource or System identity; operational Fields/owners/fold are unchanged. Disabled composer snapshot bypasses both prior and machine observers. Opaque value rendering remains allowed.

This candidate is source preparation only. It does not project a machine state universe, transitions, notices or stream readers, and it introduces no event/disposal policy. A complete ordinary consumer and independent whole model precede backend acceptance.
