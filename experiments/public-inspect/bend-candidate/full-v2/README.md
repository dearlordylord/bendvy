# Inspector lookup and lifecycle retention development

This additive candidate extends the delivered joint Inspector consumer. It is
experimental and does not close #54 or authorize production promotion.

- `component.bend` returns detached typed component projections while threading
  the entire joint World, event and lifecycle owners.
- `logs.bend` keeps component-removal and entity-despawn domains separate. Its
  closed family selector is available for multi-family schemas.
- `frame.bend` captures actual World clocks and trims each domain from its own
  actual registered-holder cursor projection.
- `retained-{workshop,garden}.bend` create actual Factory worlds and affine
  Array payload/resource owners, reserve/activate an entity, replace its real
  typed Column payload, register two separate actual System registries, run a
  failing Inspector, queue actual live despawn plus ordinary events, apply the
  barrier, run another failing Inspector, capture two frames, then retry and
  repeat successfully. The observer returns all owners. Both holder cursors
  remain zero across Inspector success and failure; no Inspector is registered
  as a retaining system. Typed lookup changes from Found to MissingEntity.

`retained-reference.mjs` executes the same public observations through the pinned
TS Runtime. Its two retaining System slots are activated through deliberately
throwing system runs; their retained cursors remain zero. These setup operations
advance TS clocks, whereas Bend registration itself does not execute a System.
Public observations therefore compare data and relative added/changed flags;
Bend's exact internal clocks have their own independent full literal oracle.
This is explicit setup instrumentation, not clock equality or full refinement.

The actual TS consumer and both emitted JS/Native applications pass all eight
complete preauthored snapshots. Four extended API negatives fail at their
intended boundaries: writing through a ValueRead, cross-schema Lookup misuse,
abstract owner duplication and undeclared concrete-Frame access from H. The
portable evidence verifier checks full outputs and all60 owned tool probes.

`development.py` freezes the complete cheap TS/interpreted applications.
`backends.py` stages the closed Bend imports and uses the shared owned installed
probe helper with ordinary verification, ancestor configuration presence guards,
a private exact environment map, raw streams, generated artifact guards and the
central descendant-supervised task runner. Checker development remains five
seconds; JS/C emission is30, compilation120, runtime5 with one Native thread and
GPU off. Large interpreted normalization timed out and its failed receipt is
retained; the timeout is not semantic acceptance.

`lookup-despawn-*` preserve the earlier mixed internal transport experiment and
its full-output diagnostic. Its original harness expected an unquoted String;
Bend returned a normalized JSON String. `reconcile-interpreted.py` checks the
retained command exit, immutable raw bytes and full independently authored
oracle after exact JSON decoding, without another child execution. Mixed notices
are not presented as a family-specific TS stream.
