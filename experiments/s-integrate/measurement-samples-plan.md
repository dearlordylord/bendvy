# Timing contract — first Dense/Sparse tranche

This measured tranche uses the actual `measurement-bend.bend` dispatcher/Host/provider/one-SystemTx workload, with its existing inner `IO.now` interval. The new Bend driver runs one identical fresh-world warmup followed by fresh-world measured work. Its TS counterpart uses actual pinned public dispatch, query reads, per-row writes and per-row Ledger updates. The authoritative full-field reference remains unchanged. The timing adapter removes TS-only per-iteration audit arrays and structuredClone calls, uses the same ordered full-field weighted U32 checksum as Bend, and still compares every final field and its checksum outside the timed interval. Sparse optional/present/absent passes remain authored timed work on both sides.

Per-world inputs remain both schemas,64/256/1024 initial entities and64 iterations. Every sample uses one fresh measured world on every backend. Native samples below10ms are explicitly flagged resolution-limited (IO.now has integer-millisecond resolution); no batching or iteration increase is introduced. Setup, warmup, final dump/validation stay outside each reported inner interval, but the unchanged five-second child-process limit includes them all. Dispatch/barriers and authored intermediate observations remain included. Seven fresh repetitions per case rotate Native/TS/JS order; a failure stays a failed sample and prevents a complete seven-sample result. A supplementary correctness invocation precedes the measured repetitions; no failed full-output gate becomes an accepted timing sample.

Pin source/compiler/Base/reference/tool hashes, backend commands and CPU5. Native uses one worker, GPU off, existing clang `-std=c11 -O3 -lpthread -lm`. Codegen30s/clang120s are distinct from checker/runtime5s. The common RSS mechanism is POSIX `posix_spawn` plus `wait4.ru_maxrss`, with process-group cleanup at the deadline; no external time utility or new dependency is required. RSS covers the entire child (imports, warmup, fresh setups, dumps and child-owned validation); it is not component allocation or steady-state live storage. Report raw samples, min/median/max, timer precision, actual failed samples and Native/TS,JS/TS ratios without approving any numerical threshold.

Readers/Lifecycle timing will use separately frozen adapters that preserve their actual dispatcher, reader/log and intermediate public observations while avoiding redundant diagnostic world dumps. Correctness evidence and unsuccessful full-output encodings remain separate; no checksum alone fills a failed complete-field gate. FailedTxn is owned by its separate transaction worker.
