# E10 integrated static access controls

Draft finite type/ownership gates, not general ECS laws or proof approval.
Subject: committed `audited-invoker` provisioning of closed `systems.motion_a` /
`health_a` and B bodies; actual `host.query` -> `query` fresh read provider.
Every negative has an unchanged compiling actual-call-site positive. Mutations
operate only in temporary copies; shared implementations remain frozen.

| Control | Actual boundary and intended rejection |
|---|---|
| Undeclared token | Closed Motion A supplied Position operation receives VelocityToken |
| Cross schema | Closed Motion A Position operation receives VitalsToken |
| Read write | Host query callback receives opaque Owner and get only; concrete Position swap is unavailable |
| Reconstruct owner | Host query callback returns fabricated Position in place of arbitrary Owner |
| Invalid return | Host query callback exchanges arbitrary Owner/Aux |
| Audit copy | Trusted audited log attempts two uses of the actual affine Audit |
| Irrecoverable mutation | Host read callback attempts to destructure/drop the abstract payload and return a fabricated replacement |

Checker bound: five seconds per invocation, exact diagnostic + actual definition
location required. No dependency/tool changes. Positive compilation establishes
these concrete signature joins only. A negative at the opaque read boundary does
not establish general destructive Type rollback: trusted concrete destructive
setters, unforgeable root construction and external destruction remain unresolved
production contracts. Successful disposal via actual structural commands is a
separate runtime gate, not this static result.
