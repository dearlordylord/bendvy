# E10 actual Host / Runtime foreign-command boundary

The new `structural-host-adapter.insert` consumes the actual `D.Runtime<Host>`,
passes its world to public `commands.insert_main`, and rebuilds the returned
Host and Runtime with their existing affine owners. It retains CommandMissing's
actual Main Type payload. This extends the old bare storage/command test to the
real wrapper seam; it does not add a new foreign result or allocator policy.

Run `python3 experiments/s-integrate/structural-host-run.py`. Each nominal schema
uses one actual threaded factory for alpha/beta. Both reserve an actual ID1;
alpha's Main10 becomes live at an explicit barrier, and a successful local
Insert80 makes its queue nonempty. Beta's actual returned handle (namespace2)
then attempts to insert retained Main90 into alpha (namespace1). Expected result:
CommandMissing, full rejected payload90 returned, complete receiver unchanged.

The fixture wraps that world in actual Host/Runtime owners. It registers a real
system instance, calls its Local capture twice through Returned/Regenerated
operations, begins/completes a real reader, and appends real typed message and
lifecycle log records using the log APIs. Header/events/escaped/observation/state
fields are explicit nonempty fixture inputs. Log lifecycle records here are
supplied fixture history, not claims that this fixture dispatched prior lifecycle
systems. The full Host trace separately exercises actual lifecycle generation.

The fresh trusted owner-return observer reads every declared receiver field:
full world rows/payload arrays/metadata/pending/Ledger/mode; capacity, size,
dropped and both physical front/rear batches of all three log buffers; bindings,
header/prior/events; complete registered System descriptor and four Local array
cells; reader interests/state; all clock fields; Audit presence; capture style;
escaped handles, observations and next mode. The actual returned Audit is then
used for an IO effect, showing legal service ownership survives. Arrays and
other affine owners are read and returned, never cloned or borrowed. Captured
closures are regenerated by the actual capture API during setup.

Both backends must match all twelve complete lines against independently written
fixture-input expectations. No summary/checksum replaces value comparison.
Compiling namespace bypass must return Queued and expose the actual changed
receiver queue; compiling clock reset and capture-registry reset must break
complete before/after preservation. Evidence records full mutant output and
first difference. An initial checker invocation reached five seconds and is not
counted as a pass; unchanged direct bounded checking passed, and the complete
runner uses the same unchanged five-second bound. No timeout increase or compiler
replacement is used. Code generation/clang keep separate existing t05 limits.

This is finite actual Host/Runtime preservation evidence for the chosen fixture,
not a universal refinement, full dispatcher trace, reader retention/performance
acceptance, physical pointer identity or global factory-root unforgeability.
No dependencies, general proofs, production layout or destructive-restoration
contract are introduced. The fixture's one threaded factory lineage is explicit.
