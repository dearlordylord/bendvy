## Exact basic-save contract

`Snapshot` is detached Data containing `version = 1`, the actual allocator `nextEntity`, ordered live entities with IDs and component fields, and resource fields. Fields use the retained ordinary descriptor keys. The actual inventory is `Payload`, `Scratch`, `Settings`, `ScratchSettings`: constructed Payload/Settings export through explicit owner-preserving codec/projection witnesses; transient Scratch/ScratchSettings are omitted while their live owners remain intact. Inactive reserved IDs are not exported as live entities, while allocator progress is retained.

The advertised public `Save.save` boundary requires the same complete `Schema<...,True{},...>` that derives the ordinary inventory and recursive traversal. Plain component or resource leaves propagate False and cannot call it. Declared constructed payload admission runs the canonical constructor/validation path and returns rejected incoming affine owners. Export itself does not rerun decoding; diagnostic validation of old/new snapshots is separate. Trusted raw schema constructors, identity/lens coherence and authored projection/inverse functions remain explicit engine-author boundaries, rather than a new language-wide secrecy or arbitrary Raw→Type reconstruction guarantee.

This basic value is a world save, not a runtime checkpoint: it does not encode namespace authority, pending command closures, registration/reader cursors, retention state, arbitrary affine owners, graph edges or machine state. Graph/machine export and restoration remain #59/#60. No global activation/cancellation/generation policy follows. The fixture uses the existing closed String/JSON renderer and installed Base/IO effects; no serializer dependency is assumed or introduced.
