# Actual basic World export consumed slice

This experimental implementation exports actual World entity/resource owners into detached basic Snapshot Data. It is not the complete public Snapshot facade: #46 constructed descriptor eligibility/failure boundary and #38 adoption remain open. No restore inverse, codec truthfulness, constructor secrecy, capture ownership or new save error policy is selected.

`export.basic` reads actual `nextId` by a field-exact owner-return accessor, then actual `W.handles` (canonical live namespace/IDs), `W.with_store` and `W.observe_resource`. All World fields, actual live Array and pending continuations are returned unchanged. The detached DTO is version1/nextEntity/entities/name-keyed component and resource fields. Runtime checkpoint registrations/events/queues are not serialized by this basic DTO.

`fixture` supplies Workshop/Garden, arbitrary Type Payload owning a two-cell Array, persisted/transient columns and resources, retained actual Codec Data, and a closed erased owner-return projection. The persisted component name comes from the one actual common #56 Declaration module indexed by S and Payload. Resource names are fixed trusted closed fixture metadata; a general canonical resource eligibility registry is not claimed. Provider metadata/projection truth is trusted, not type-proved.

The same actual returned Factory creates the two nominal Worlds. Actual reserve_id runs three times per World; only first two handles are activated. Source refusal branches preserve the actual World or rejected creation resource/Factory without fabricating a World. Actual Col.swap provisions both saved and transient rows. Codec Data remains in the returned store/resource owner. `F.save` omits transient fields without calling their projectors; a separate complete owner observer reads transient values for verification.

Two complete saves each have an immediate full named-fixture owner observation before mutation. A real saved-row replacement changes both cells, and real resource replacement changes both saved resource cells. A third save follows. The first/second detached Data remain observable after mutation. Internal validation of first/after Data uses codecs read from the actual returned World and actual #46 D.owned; it returns full Checked values plus the actual World, without converting rejection into a public save refusal.

The complete independent pre-output oracle compares every DTO field, all fixture payload cells, all reserved column IDs1/2/3 including absent inactive3, populated row lifecycle stamps, retained codecs, namespace/nextId/highWater/capacity/depth/liveness handles, empty event/registration lists, pending count, nextSystemId and clock. It is complete for this named fixture, not arbitrary runtime checkpoint inspection. Actual live Array and pending closure identities are retained in the World, not encoded in the observer Data. Empty/unsupported constructor observation markers fail the strict oracle rather than receiving normal credit. The ASCII formatter reuses the prior128-step per-Raw diagnostic budget and does not claim a generic JSON serializer.

The actual TS reference calls constructed/transient descriptors, Decode, public System/commands/applyDeferred and Runtime.snapshot. It compares complete basic DTO fields, with empty relation/machine extensions explicitly outside the basic scope. TS creates then removes ID3; Bend retains an inactive reservation, matching allocator/live-entity observables but not timed operation counts. TS snapshots retain live array aliases; their separate independently authored lifetime oracle intentionally expects changed first/second arrays after mutation. Bend independently owned saved Data intentionally retains original values. No fake lifetime equality or comparative timing claim.
