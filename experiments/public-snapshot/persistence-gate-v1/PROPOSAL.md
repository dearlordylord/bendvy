# Persistence Gate source feasibility

Governing contract remains #58 (`docs/parity/snapshot-export.md`), with #46 validation and #38 identity prerequisites. This unexecuted experimental sibling studies only the static eligibility and owner-return shape. No World save API, wire format, new law, codec inverse or ownership policy is selected.

`reference-source/canonical-component.bend` is byte-exact #56 canonical Declaration/Token source (e4c9c53e, source-feasibility only). Gate is indexed by that actual `Declaration<S,P>` rather than a separately invented key/schema wrapper. `reference-source/typed.bend` and utf16 are exact existing #46 Data Raw/Codec sources; their existing finite replay does not qualify this new composition.

`Gate<S,P,declaration>` is an affine trusted-author sum: Transient omits without inspecting or consuming P; Persisted carries an explicit `P -> P & Raw` projection and Data validator Codec. Export returns the same owner and an independent Data field. Export does not run a decoder, matching the distinction between TS static eligibility and its export body. Codec presence is only a Data-validation provider shape: it does not imply an implemented constructed descriptor, inverse Raw-to-P, roundtrip, truthful projection or complete descriptor Gate. #46 still owns that integration prerequisite. Public constructors can be forged or misconfigured by trusted schema authors; phantom nominal indexes and signatures do not establish constructor secrecy.

Source subjects pair plain-declaration refusal with persisted legal calls, and cross-schema refusal with same-schema legal calls. Transient legal shape retains the same arbitrary Type owner without requiring a projector. The fixture payload owns an actual Array and reads it through owner-returning Array.get. Proposed check-only subjects use the unchanged five-second development cap, raw intended-error classification after collection. No subjects have run. No unchecked public World lookup or I.Frame save alias is introduced.

A later full normal application must integrate actual World components/resources/allocator and validated transient metadata, two schemas, actual same-schema foreign Worlds, owner/saved-lifetime mutation checks and complete TS/JS/Native outputs before backend delivery. Current leaf function consumes its Gate, so a reusable multiple-save API is explicitly unimplemented. Matching return types alone cannot prove returned owner identity or callback noninterference. Resource declarations and general schema aggregation are not yet connected. These gaps belong to #58/#46, restore construction/staging to #59, relation/machine extension to #60. No existing Inspector/query/Decode runtime receipt transfers to this proposal.

Only isolated `experiments/public-snapshot/persistence-gate-v1` files are owned; no shared src change. `source-proposal.json` binds exact copied and authored source bytes. Source/check/runtime qualification remains separate from source authorship.
