# Reached unregister invalidation control

The isolated scheduled closure changes one expression in
`registration.remove_checked`'s successful branch: retain `registrations` instead
of `without(registrations,id,name,access)`. Exact identity/namespace validation,
returned capture, actual ordinary entry and the entire workload remain unchanged.
The mutation is reached through Capture.unregister → Local.dispose → Reg.remove.

This detects omitted registration invalidation through complete final World
metadata. It is not a claim that a second disposal executed, nor a gameplay
arithmetic or generic lost-capture mutant. Generic affine capture transport cannot
fabricate an arbitrary replacement owner; duplication controls are separate.
Frozen source.tar.gz retains all 58 Bend modules and two namespace sidecars.
