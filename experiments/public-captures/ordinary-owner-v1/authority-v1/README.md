# Capture authority controls

`positive.bend` checks actual `ordinary-captures.define` with a normal declared
resource write and arbitrary affine Pack. The ordinary/scheduled consumers are
its runtime counterparts. Five intended failures cover instance duplication,
nominal schema mismatch, supplying a read declaration to the write body, entering
a raw Tx API using an abstract gameplay owner, and escaping that owner as World.

CHECKS retains each five-second source check and raw diagnostics; SOURCE-PINS
binds the literal source closure. These are compiler boundary checks, not proofs
of language-wide confinement or runtime mutant evidence. Raw trusted constructors
remain separately scoped, as in existing ECS authority contracts.
