# Failed growth, retained pending work and retry

One actual IO-created World retains an already committed ordinary Batch spawn.
Its actual pending slot has index one/generation zero and capacity two. Before
new reservations, a clearly marked trusted-admin malformed key uses the same
actual namespace/generation and index=prior.index+actual.capacity. Canonical
despawn admission must reject this nonreserved index before masked Array access.
This raw-constructor boundary probe is not described as ordinary authority or a
foreign-world handle. Full Tx/World ownership is observed before and after it.

A separate ordinary Batch reserves seven more affine arrays and grows the actual
allocator to capacity sixteen. Complete Tx and prepared-record observation retains
every generated position, reservation receipt, Array owner and callback. Actual
Batch failure returns all seven original payload arrays. Pending inverses clear
the failed slots and logical-order entries at the current capacity, preserving
the earlier committed pending work; failed IDs remain consumed.

Canonical failed-handle despawn/read/write attempts are observed, including the
refused incoming array. A retry records its actual fresh returned handle, then
the real barrier applies both prior and retry streams. Complete physical slot and
component trees, generations/phases/free/order, all affine return owners, stamps,
trace, events, queue/undo counts, resource, registrations and clock remain visible.
Observers consume and return actual owners; callbacks are opaque and unexecuted.

CPU6/default five-second source check reports only three actual IO dependencies.
Independent model and backend execution remain pending. No capacity, failure or
numerical policy is introduced.
