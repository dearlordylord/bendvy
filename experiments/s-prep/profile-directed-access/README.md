# Profile-directed candidate access controls

Fresh standalone controls of the exact JS direct-raw-swap and Native
boxed/direct-raw-swap29-module overlays. Runtime owners remain affine `Type`;
actual public callbacks and existing literal/type oracles are unchanged.
This is finite boundary evidence, not full22 gates, universal confinement,
production adoption, law/proof approval or a performance result.

Existing root `materialize-controls.py` creates fresh per-role control copies
with `--raw-snapshots --slice-host-fixtures`. Existing `access-run.py` then runs
on CPU10 with explicit `BENDVY_CHECKER_SECONDS=15`. Execution metadata retains
commands, source/runner pins and failures; no existing runner is edited here.

Exact requested coverage per role:

- Nine access cases: one positive; undeclared token, cross-schema token,
  writes through read, owner reconstruction, invalid owner return, historical
  String duplication, affine Audit duplication and irrecoverable abstract-owner
  destructuring. The historical String case is not an affine-owner claim.
- Eight static provider cases: two positive and six negative, as enforced by
  the existing runner. These are not eight negative cases.
- Sixteen actual factory/world controls across Motion/Health, cached/raw
  observation, static/original-point callback and Native/JS execution.

The original access receipt hardcodes `checker_limit_seconds:5`; its checker
honors the explicit environment15. Receipt bytes are preserved; execution
metadata records the effective15-second limit. Kernel and proof wrappers are
unchanged; codegen30/runtime5/clang120 limits remain unchanged. Partial evidence
or a failed factory subrun cannot pass this aggregate.

Result: both exact roles pass nine access cases, eight provider cases and all16
factory controls. Each factory matrix executes both Native and JS. Both original
29-source input manifests match their actual file bytes. Deterministic compressed
receipts, complete raw factory outputs and command logs are indexed in
`evidence/summary.json`; verbatim input/control manifests are also retained.
Generated C, binaries and derived source copies remain local, with their hashes
in original receipts; they are not committed. Existing receipt absolute paths
refer to retained local execution artifacts, not portable package paths.

The JS outer sequential supervisor was paused and stopped before Native launch
to prevent the existing runner's shared `static-world` output-directory collision.
The JS child completed untouched; Native ran with a separate evidence parent.
No collision target or extra experimental retry was executed. No observed failure
occurred in either role's controls. This does not pass the full Host/performance
aggregate or any missing runtime refinement gate.
