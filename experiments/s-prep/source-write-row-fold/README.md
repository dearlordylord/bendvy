# Source write-row fold (experimental)

This bounded source candidate keeps the original abstract callbacks and moves World/Rows/Tx reconstruction to the end of a selected row fold. A generic affine seventeen-field `PrototypeWriteFold` carries arrays, metadata, ledger, transaction journals, pending commands, pings, marks and context directly. Namespace/missing/live checks and their fallback callback paths remain per row. Each returned affine Main/Ledger owner is consumed and restored before the next row. Existing public headers and original callback bodies are preserved.

The exact base is `/tmp/bendvy-row-owner-split-reproduced`; input-pins.json binds its 29 sources. materialize.py applies the two fail-closed patches to a fresh overlay. Candidate closure: `f3f9cc44c61216fbf4abf18243feba74d102c39df85cd6b89f6a6c6c8d8f1d5d`. Only held-adapter.bend and measurement-bend.bend change. `derive.py` records source construction; the checked patches are the reproducible recipe.
