retain all original field projections, immutable views and Tuple/Found/Some results,
returning the consumed row owner. Writes keep the unique saturated done edge,
evaluate every original result expression in order before mutating changed slots,
and skip a store only when the original done parameter traces through its caller's
pure const projections to that same owner slot. Raw ownership remains affine;
new cached Data views, inverse and mark nodes remain fresh. Reserved names, ordered
fields, unique callers and unchanged getter projections are checked fail-closed.
These local guards depend on this audited closed source/input catalog; they do not
establish arbitrary getter/proxy/FFI/alias safety for newly admitted programs.
