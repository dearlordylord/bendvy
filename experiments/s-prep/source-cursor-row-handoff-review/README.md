The current [query](/tmp/bendvy-slot-host-v1/experiments/s-integrate/query.bend:284) takes a selected Some Main, restores it and prepends its ID. It preserves bounds→live→flag selection→Main presence order. The [descending loop](/tmp/bendvy-slot-host-v1/experiments/s-integrate/query.bend:315) starts at high, decreases every iteration and prepends, yielding ascending consumption before callbacks begin. The handoff may replace restore+ID with an affine detached `(id,Main)` row, but must preserve every branch and complete metadata/Aux columns. No callback may run during this scan.

The [Motion taken provider](/tmp/bendvy-slot-host-v1/experiments/s-integrate/held-adapter.bend:664) consumes columns+Some Main and ledger. Its [opaque row owner](/tmp/bendvy-slot-host-v1/experiments/s-integrate/held-adapter.bend:617) holds only current Main raw array/cached scalars, ledger, selected handle, pending undo and marks. Existing callbacks therefore can remain byte-identical and receive only their original providers.

Feed the evacuated columns and current Some Main directly to the ORIGINAL taken helper. Preserve its original [Motion return](/tmp/bendvy-slot-host-v1/experiments/s-integrate/held-adapter.bend:659), Health equivalent, handle selection, paired pending flush, journal order, duplicate marks and total accumulation. This reinstalls each returned Main before advancing. The batch keeps future Main owners affine and private. All command/event/publication work must occur only after complete drain, through the original [finish/commit boundary](/tmp/bendvy-slot-host-v1/experiments/s-integrate/transaction.bend:176).

The safe adapter scope is the private measured entries at [Motion query](/tmp/bendvy-slot-host-v1/experiments/s-integrate/measurement-bend.bend:451), [Motion cursor consumption](/tmp/bendvy-slot-host-v1/experiments/s-integrate/measurement-bend.bend:540), and Health619/706. Ordinary [Host query](/tmp/bendvy-slot-host-v1/experiments/s-integrate/host.bend:101) and public general-getter route remain unchanged. Generic Core `M/A/L:Type` and complete [World/Rows](/tmp/bendvy-slot-host-v1/experiments/s-integrate/storage.bend:77) are retained. A concrete packed Main consumer is a private specialization, not approval to narrow generic payloads to Data.

Concrete blockers to a drop-in implementation:

- An ordinary World with future holes cannot be passed to generic callbacks, snapshot observers, public providers, rollback or finish. Represent the incomplete context as a distinct affine batch, never as an externally returned World.
- Before any generic fallback, recover current AND all remaining detached rows into columns and return their ascending Data IDs. Invoke the ORIGINAL cursor loop on that complete World. Honor its complete nonidentity returned owner; never reattach stale pre-fallback owners afterward. This rule also permits the generic callback to change membership/context of subsequent IDs.
- Initial LedgerNone must execute original query+fold BEFORE evacuation. Although producerSome and old taken/returned normally retain ledger presence, an explicit None-ledger drain/recovery route must consume every detached owner before falling back. Dropping the remaining batch is a bug.
- Same-schema nominal types do not prevent forged duplicate IDs, foreign namespaces or exported-constructor misuse. Scope must be an exact closed producer/drain pair; retain ordinary external cursor validation and public headers. Exported helper/type constructors do not establish production confinement or replace negative authority controls.
- Array modulo behavior must not silently replace namespace/bounds/high checks. Producer-selected unique ascending IDs justify only its closed route, not arbitrary supplied cursors. Selection includes Required/Present/Absent/Optional, missing/dead/empty/high/capacity branches and cached/raw discrepancies.
- An affine Type list adds owner-bearing row/list transports and may add RFC seals. Source-level saved swap/restore calls do not prove fewer Native requests or elapsed improvement. Count actual reached generated code before expanding scope.

Required fresh candidate gates: both-schema complete65 fields; literal owned arrays depths0–4 or1/2/4/8, every cell and all raw/cache scalars; retained immutable Data; multiple selected ascending rows and all selections; foreign/missing/dead/bounds/empty and ledgerNone fallback; arbitrary affine owner clone/cross-schema/write-through-read negatives; genuine nonidentity generic returned World after full recovery; repeated Main/Ledger writes, Pair/Main-only/Ledger-only inverse order, pending flush, duplicate marks, successful publication and complete rollback. Live compiling mutants must detect omission of a recovered owner, descending callback order, stale-owner reattachment, ignored namespace/selection, lost paired inverse and mark. Existing supplied-ID Tx gates alone do not exercise enumeration/evacuation.

## Concrete pre-evacuation shape blocker

The earlier statement that no normal-path defect was found applies to valid balanced factory columns. Public `Rows` do not enforce that shape. Source-derived counterexample1: one physical Main leaf, capacity/high2, both metadata-live entries True. Original cursor restores after probing ID2 and therefore also selects ID1; v2 handoff leaves None after ID2 and skips ID1. Counterexample2 (Native): `ANode{ANode{LeafNone,LeafNone},LeafSomeMain}`, capacity/high4. Installed [Array.size](/home/node/.bend/bend2/base.bend:2245) reports4 from left depth, while [swap.at/go](/home/node/.bend/bend2/base.bend:2267) sends IDs3/4 to the same shallow right leaf. A size-only guard would admit this ragged tree and still change callback work. These are source-derived cases; this reviewer has not executed them and claims no fresh runtime mutant result.

Root now requires a NEW owner-preserving recursive balanced-shape AND size guard before evacuation, rebuilding both children and retaining every affine owner. Unknown/ragged/capacity mismatch must execute the original query+fold before taking rows. The guard's O(n) work, reconstructed-node allocations and overflow/domain handling must be counted/timed as actual candidate work; it cannot be treated as free or replaced by an unapproved universal factory certificate. Existing v1/v2 sources remain immutable and are not generic-equivalence-ready.
