## Concrete mechanisms

Health's nominal MainSlot has9 fields, `cls_fit(9)` rounds to16words; Motion has7fields rounding to8words. Each independently executed MainSlot site requests one block/update, explaining the exact8word/update Health difference. Wider nominal payload transport is a concrete requested-size cost, not a demonstrated elapsed cause.

The separate extended recipe records original `blk_read`/`blk_write` calls and their boolean modes at function entry, plus `blk_loc` calls. It preserves argument expressions/evaluation and original function bodies, adding read-only-parameter counter hooks. Arraymode totals reconcile with source-site totals, and allocation/RFC/word totals equal the base method. For BOTH schemas and BOTH sizes, with U actual updates:

Thus no per-update height growth appears in these actual helpers. Generated `blk_read` directly indexes H[loc+i] or the scalar buffer; `blk_write` mirrors it; `blk_at` masks an offset. This flattened Native representation is not the recursive source Array tree. Helper counters do not enumerate compiler-generated direct constructor-field memory accesses or establish cache misses/locality.
