# Direct literal Tuple scalar receivers

This is an exact-input generated-JavaScript causal probe. It leaves all Bend sources, the compiler, Native binaries, original helpers, public APIs, callback bodies and generic affine component types unchanged. It is not a shipped compiler pass or a universal ownership/refinement proof.

The catalog admits the frozen identity-query-v3 Motion and Health batch programs after the independently pinned row-reuse and nullary Data-token passes, plus eight exact current-source transaction/suppressed-owner programs. Every source closure contains the actual 29 modules. Fixture extras, producer recipes, intermediate programs and receipts are separate mandatory pins. Unknown inputs, changed producers/source files and occupied outputs fail closed.

The Acorn analysis accepts only a direct named call whose literal pair has exactly the ordered plain `$`, `fst`, `snd` properties. The receiver is a unique immutable top-level function with simple parameters, and every use of its pair parameter is a read projection. Whole-pair/tag/escape/capture/shadow/write/method/arguments/context/reflection cases refuse. A private cloned receiver takes two scalar parameters in the former pair position. The original field expressions execute once in their original order, between the same adjacent call arguments. Original functions and nonliteral edges remain intact. There is no added per-call closure or alias mutation. The closed catalog and producer guards remain essential; this is not a general FFI/proxy/identity optimizer.
