## Mechanism and admission

Fresh V8 phase sampling first tested the proposed getter/View/Four scalar bridge.
Main getters accounted for only approximately 2.3 MB of 239–240 MB sampled per
schema; inlining makes exact expression attribution uncertain. That bridge was
not implemented. Returned owners, live/take, ledger continuations and query
advance dominate the observed allocation attribution.

The dense lane has already flattened World and Rows into a private Type Fold.
Its concrete reached chain is:

```
Cursor loop -> packed step -> guard -> live -> taken -> returned
```

Motion uses `prototype_packed_prototype_flatfold_motion_*`; Health uses
`prototype_packed_prototype_journalledger_health_*`. Five private copies thread the
original Fold as an additional argument. Only the Cursor loop's step call changes.
Only `returned` replaces its final Fold literal with 17 ordered RHS temporaries,
then 17 own-field assignments and return of that original Fold. All RHS expressions
finish before the first assignment. Array restoration, Main slot and ledger
record construction, selected Handle, pending-journal flush, total arithmetic,
marks, commands, pings, metadata, guards, and callbacks retain their original
expressions and order. Failed/dead/missing/foreign/no-ledger paths call the original
fallbacks, which can return a fresh Fold for the next iteration.

Admission is fail-closed: exact complete-program SHA; all source/build and
intermediate pins; exact five helper and producer/consumer bodies; unique incoming
saturated call edges; no function-value escape; the source's full affine Type
header and fields; plain exact Fold producers; no reflection, prototype/accessor
mutation, Proxy, delete, eval, arguments observation, shadow replacement, captured
Fold, or unknown owner use. Output and receipt must both be absent. The original
state is read only through its known field projections before being threaded.

The source Type still quantifies arbitrary `M:Type`, `A:Type`, and `L:Type`.
This does not restrict raw components to Data. Immutable Main/Ledger Data snapshots
are never mutated. The interpretation relies on these pinned closed producers and
source ownership; it does not legalize mutating arbitrary JavaScript records or
exposed old Type aliases.
