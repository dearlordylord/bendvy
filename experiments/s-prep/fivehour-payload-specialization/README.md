# Original four-cell payload specialization

Actual finite correctness controls pass on Bend2.0.35 Native O3 (one worker/GPU off) and JS. All original payload public headers are preserved, with nominal Type owners unchanged. Native's `four` destructures the exact balanced four-leaf shape once, returning the rebuilt owner and complete Data observation; any other shape reconstructs the original tree and uses `original_four`. `scalar0_swap` safely descends/reconstructs the left path and returns the original zero value. No size lookup, unsafe annotation, cloning, foreign helper or Data-only owner is introduced. JS uses **original-payload.bend**, retaining existing flat Array.get/swap intrinsics; structural JS slice/concat is intentionally not the proposed binding.

The integration boundary is a copied private payload module with its existing relative `types.bend as T` import bound to the unchanged nominal types. Native binds the copy to `native-payload.bend`; JS binds it to `original-payload.bend`. Existing position/vitals/motion_ledger/health_ledger get/swap and velocity/armor get names/signatures stay exact. This package does not edit the main provider, candidate storage/query, installed compiler or reference sources. Any consumer must retain these exact bindings and run its own complete caller/provider controls.

Balanced one/two/eight-cell fallback includes physical returned-owner cells beyond the four-cell view.
