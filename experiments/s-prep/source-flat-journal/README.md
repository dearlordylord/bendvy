# Private recursive journal experiment

Draft implementation and evidence ledger; not a production API or performance keep.
Base is the exact fold/noAux29-source join. Candidate-only transaction, Held and
measurement private transport is authorized; original callbacks, public function
headers and generic routes stay present. `verify-source.py` checks this explicitly.

Private MainUndo stores namespace/id/old/rest in one recursive constructor;
LedgerUndo stores old/rest. Private marks store namespace/id/rest. This removes
List/Inverse/Handle nesting. Journals contain scalar inverse values as the original
runtime does; component Main/Aux/Ledger owners retain their affine Type kinds.

Incoming legacy inverse/mark lists convert recursively without changing their
head-to-tail order. Valid private row writes prepend new entries. Every generic
fallback materializes the complete journal, calls the unchanged generic callback
and providers, and repacks every returned entry. No identity callback assumption
or omitted failed write is used. Private success retains flat marks until direct
mark publication with original namespace/bounds/high/live guards. Private failure
replays LIFO inverse entries using concrete checked restore providers, rebuilding
schema-bound Handles at restoration boundaries. No abstract generic H is invented.

The original generic Tx API and bodies remain unchanged. Newly generated private
measurement state/finish functions bypass legacy materialization on normal commit.
Only two original concrete measurement invoke bodies redirect to that transport.
A separate private point wrapper deliberately materializes journals for full-field
protected Tx observation and fallback/rollback controls. Its cost is not part of
the measured dense path. All original authored callback functions remain byte exact.

Limits: diagnostic checker15, emission30, private approved Clang19 compile120,
runtime5, CPU8, oneworker/GPUoff. No compiler/kernel/reference/dependency/law/proof
change. No timing is accepted until actual full65 and private Tx/mutation controls.
Universal refinement, full22, production confinement and product targets remain
separate. Foreign marks, repeated marks and incoming legacy entries must not be
silently dropped to obtain performance.
