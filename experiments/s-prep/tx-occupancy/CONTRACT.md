# Private active transaction diagnostic contract

Instrument a materialized copy of the actual indexed runtime, preserving opaque callback types and full public observations. Every inspected affine command list is returned in its original order with every Type payload retained. Inspect actual physical commands, pings, inverse entries and marks after append and before finish; retain records through successful publication or failed rollback. Record rollback inverse drain and commit mark drain separately. Diagnostic records are transported at existing trusted IO completion boundaries, outside timing acceptance.

Finite invariants: physical list traversal counts agree with independent append/drain counters at every recorded point; empty begin is distinct from nonempty finish; failure removes staged publications while restoring actual values; successful commit drains marks/inverse and transfers staged command/event owners. Compiling metric mutants must break the count oracle while preserving complete public observations. Actual workload records, finite fixtures and unsupported cells remain distinct. No universal law/proof, new dependency, timing threshold or optimization is introduced.
