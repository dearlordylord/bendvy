These are scoped finite tests, not universal capability confinement or runtime refinement. Trusted root/schema provisioning can construct detached concrete Worlds/Frames; it must not be confused with abstract gameplay capability authority. The fixture intentionally aliases its main/aux family to isolate repeated-operation transport; the independently authored application must separately exercise independent affine families, optional membership and the full external trace. Exact registration/retry and integration/performance gates belong to their connected packages.

`each_rw_read` grants the explicit full bundle (main RW, aux Read, resource RW, event Write, current-entity despawn and one typed spawn payload). Registration must describe every supplied grant, including unused ones. `each_rw_read_resource` and `each_rw_read_events` are smaller fixed bundles; `each_read` supplies only reads. Follow-ups: composable arbitrary-arity capability declarations, richer filters, multiple resource/event types, ergonomic schema binding and dynamically extensible schedules. These simplifications do not reduce the full-core goal.
