# #47 complete application timing/scaling candidate

Scope: actual `application-reference.mjs` versus `D.main()`; every repetition
executes the unchanged complete 62-row application across two nominal schemas.
Fresh descriptor/runtime/World/Factory/registrations and cursor owners are created
inside each callable invocation. Both state families, full four-cell Array
neighbors, deferred barrier, failed-write rollback, stale expected state, valid
and invalid raw errors, both changed readers and same-value writes are retained.
Descriptor-only observations, approved foreign divergence and administrative clock
controls remain semantic gates; they are not mixed into this common timed work.

Scales are complete lifecycle repetitions 1/2/4 (62/124/248 full rows), not reduced
query/output work. This does not establish entity-count scaling or full-core ECS
qualification. No implicit default, graph-validation policy or numerical tolerance
is added. Existing SPEC performance goals and root #28 regression stay separate.

The source-bound stage hoists only static Node imports. All remaining original
TS statements are mechanically enclosed in a fresh `run`; `D.main()` is invoked
inside the Bend post-Begin effect continuation for every repetition. Complete
strings, UTF-8 conversion, one LF per row, capture/retention and FNV digest happen
inside the monotonic timing region. Output flushing occurs after End. Compiler,
Node imports, process startup and stdout flushing are excluded from region time;
whole-process time is separately retained. Independent generated-code inspection
must confirm fresh workload/effect sequencing and no hoisted repeated application.

Timer effects/capture are copied unchanged from the reviewed parity-features
helpers. Owned raw-stream supervisor reuses its reviewed descendant cleanup locally;
no shared harness is modified. Source, exact stage inventory, wrappers/adaptations,
complete TS reference inventory, three reference HEADs/manifest, installed Bend/
Base/effects/config, resolved binaries/libraries/Clang resources, generated programs,
prospective artifact absence, all stdout/stderr logs and source guards are bound
before/after every command. Native uses one thread, GPU off. Checker5s, emit30s,
Clang120s, execution5s; timeout is inconclusive. The compiler's intended foreign-
timer check refusal is separate from pure-driver typechecking, never an ECS proof.

1. `python3 experiments/public-component-state/timing/stage.py --output <fresh-stage>`

3. Review stage/actual repeated Node observations and timing source before Native.
4. Omit `--preflight` for bounded JS/Native complete-output equivalence at all scales;
   independently review effect sequencing/generated source and semantic receipt.
5. Run with `--timing --semantic-receipt <receipt> --quiet-window <integrator-context>`
   only after quiet-window admission. Keep every pair/sample/full output/telemetry.

Timing copies the existing contract's 20 balanced AB/BA pairs, two warmups and seed
per JS/TS and Native/TS comparison at each scale. It reports all ratios/medians with
load, selected CPU activity/frequency and pressure before/after each pair. It adds
no sign-test alpha, threshold, allowed regression or automatic quietness claim.
Contended observations cannot be treated as performance acceptance. Root reviews
and qualifies the evidence; changing a batch/workload requires another frozen stage.
