# Experimental candidates — not approved, no ECS proofs

These statements are saved for shared falsification/review before any proof is written. They are not `LAWS.bend` approval or universal guarantees.

1. **Exact repeated update:** for a Motion row `(x,v)`, n executions produce `(x+n*v mod 2^32,v)`; for Health `(hp,d,a)`, n executions produce `(hp-n*d mod 2^32,d,a)`. Pin helper arithmetic and unchanged read/unselected components so a constant or missing update cannot satisfy the claim. Present fixture: n=3, Motion=(0,2), Health=(20,3,1), observed `(6,2)` and `(11,3,1)` on both backends and TS. Finite checking only; boundary, wraparound, n=0 and arbitrary rows remain untested. A no-op update predicts `(0,2)`/`(20,3,1)` and is distinguished by these observations; no compilable runtime no-op mutant has been run.
2. **Authority confinement:** every accepted system can update only its declared writable components; constructing an undeclared writable grant from read access must be impossible. **Falsified for this API**: `forge.bend` is a planted compilable bypass, `bad(ReadMotion)` fabricates `WriteMotion`; native and JS output 99. Direct read-write rejection with its positive control does not establish this law.
3. **Schema confinement:** tokens from another schema cannot authorize an operation on the current world. `cross-schema.bend` rejects HealthToken where MotionToken is required and paired control checks. This is finite type-boundary evidence, not proof of global authority confinement; the forge already defeats that broader property.
4. **Storage ownership:** orchestration consumes and returns exactly one world; callback receives declared fields only, never the world. Worlds have kind Type and are never marked `+`. This structural observation does not prove safe runtime aliasing, preservation for arbitrary systems, or refinement.

Approval request for future proof work: review the exact quantified update law (including U32 modular semantics), schema-confinement scope and ownership/refinement distinction after redesign/falsification. Do not approve authority confinement in its current form: a counterexample exists. No approval is recorded or inferred. Model proofs, executable-function proofs, finite trace comparisons and universal runtime refinement are separate gates; only finite comparisons and compile probes are present here.
