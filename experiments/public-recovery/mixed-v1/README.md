both matched the complete 16,673-byte independent oracle without retries or
model repair. See runtime-v1/actual-attempt01/manifest.json.

capture recovery and a whole Array resource into one shared journal. The new
resource leaf derives its canonical path through State.Left and the World resource
split. Gameplay receives only ordinary declared grants, never a lens or inverse.

first writes to both components, resource element swap, capture replace, second
writes to both components, resource replace, capture element swap. The complete
recovery product retains each displaced owner in its typed domain. Global LIFO
undo restores every domain together while preserving monotonic World.clock.

rollback and genuine foreign-world rejection with colliding registrations.
Both worlds, all allocated component payloads/stamps, captures, full resources,
registry cursors, input/output owners and every recovery row are observed.
The existing schema provisioning trust boundary is unchanged. No host IO,
arbitrary user callback inverse, automatic finalizer or deep alias undo is added;
normal #50 capture persistence remains unchanged.

Joined acceptance also uses retained resource-only, component/capture and
heterogeneous consumers, relevant static authority controls, reached incomplete
recovery mutations, actual TS shared-value evidence, prior rollback controls and
