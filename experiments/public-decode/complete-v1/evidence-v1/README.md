consumed source/helper joins, original terminal commands/raw receipts, full

bounded oracle, including all owners.

artifact qualification. Dependency bytes, including the currently untracked

plan joins. Those snapshots preserve observed evidence; they do not silently
promote these dependencies or make a clean root checkout executable.

reference, subsequent independent correction and source development history
remain explicit. Later-added helpers are not assigned to original execution.
