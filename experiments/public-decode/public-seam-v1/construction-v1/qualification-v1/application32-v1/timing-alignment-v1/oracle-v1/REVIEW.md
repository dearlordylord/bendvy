# Selected32 independent lifecycle expectations

These models are authored from the ordinary canonical Bend calls and pinned TS
public calls before any subject execution. The historical independent codec and
physical-world model is reused as model source, not as runtime evidence. The new
registration, queued receipts and complete TS lifecycle are derived explicitly.
The source-basis file binds the final observer source and all subject dependencies.

The complete order is Workshop Insert, Spawn and Resource, then Garden Insert,
with eight codecs in each group. Insert obtains the query twice and calls the
actual immediate write. Spawn reserves and defers activation/population. Resource
setup validates the constructed seed before the gameplay write. Every model
retains the original Raw, both affine word and flag arrays, canonical ownership,
errors, before/committed/barrier observations and final instance recovery state.

The native supplement contains all physical column slots and stamps, allocator
live flags/capacity/depth, clock, registrations, pending count, resources, returned
packets, errors and FIFO payload receipts. Its registrations are application32 id3,
queue id2 and seed id1; next system id is4. The TS supplement contains every actual
debug field, all original/incoming owners, complete checked result, all receipts
and target. Its frame/tick sequence is2/3,3/4,4/5. Nothing is projected out of either
supplement to obtain equal physical representations.

The common observer reports logical accepted requests separately from physical
lowering. A successful Spawn committed snapshot has three native pending closures
(one Marker stage plus activation/population) and two TS pending commands. Both
retain two logical receipts, with the complete owner payload and FIFO order.
`receiptLoweringMatches` checks the bounded lowering against the actual queue;
it does not assert that the two internal queues are equal. The id0 live sentinel
is excluded only from entity enumeration; full native live flags remain intact.

The common models are independently derived through both backend observations and
must be exactly equal. Their wire forms differ honestly: Bend pure String prints
the escaped, quoted JSON String and one external LF; TS prints the JSON text and
one LF. Native Whole typed constructor names are rebound from the frozen source
inventory. This is source/model readiness, not runtime, timing, public-policy or
universal authority qualification. Historical full-entry source deadlines remain
incomplete; focused source acceptance does not replace them.
