# Proposed matched interval and work inventory

Source-only proposal; no clock or numerical criterion changes.

Per each of32 fresh cases: construct full codec/Raw/owner inputs and resource
constructor; construct actual World; register/invoke seed; reserve one entity;
commit typed Value packet; seed barrier; register/invoke queue; stage one Marker;
register/invoke main system; capture original/before; construct/check raw input;
perform actual operation; finalize transaction/Local; capture committed; final
barrier; capture full final application report. Main Insert performs two real Value
selection scans. Successful Spawn adds one reservation/materialized Value; rejected
Spawn adds none. Resource mutation is immediate. Individual validation refusals
are normal completed systems with exact original affine input unchanged.

Workshop24 + Garden8, all8 codecs and original case order. At least32 complete
resource constructions,96 seed/queue/main registrations and invocations,64 barrier
applications. Exactly16 Insert cases (two scans each),8 Spawn,8 Resource. No new
abort workloads. Underlying raw validation/constructor/body counts depend on the
established native provider and TS APIs; enumerate them from retained source,
not assumed byte equality or fabricated matching work. All32 fresh worlds remain.

Whole lifecycle timer begins before the above runtime/input construction and
ends after every full matched public report is materialized/captured. Raw input
conversion, constructor/validation, ordinary registration/invocation, actual
queries/world operations, finalization/undo disposal, deferred delivery and
observer/serializer/capture are in-region. Static imports/type checking/compilation,
process startup and final output flush are outside, with whole-process time kept
separately. No phase subtraction claims pure ECS speed. Reuse existing complete
capture/timer and paired collector after exact reviewed interval binding.

Current sources still expose full backend diagnostics separately: native physical
stores/lifecycle/clock/Local and TS debug dump retain native representations. The
common public observation serializer is implemented as a source candidate. It retains
full input/canonical/returned payloads, errors, all entity/component/resource
values, real handles and pending order at original/before/committed/barrier, not a
checksum or reduced successful-value trace. Public owner flags/original fields now
match both payload declarations; JS alias identity is not normalized. Cross-backend
mapping must explicitly retain backend-specific errors/IDs where approved semantics
differ. TS prepare() now performs codec/case/64-field/array setup inside callable run(),
including actual shared input aliases within that lifecycle. Bend cases remain typed
Data constants; compiler folding/type erasure is not assigned fabricated setup cost.
Those source/observer decisions are a review boundary, not permission to
replace historical full semantic controls.
