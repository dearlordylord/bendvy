# Ordinary deferred assembly candidate (#46)

Separate extension of frozen generic-assembly-v1; its source bytes are unchanged.
`assembly.bend` is generic in schema, store, component owner P and resource owner R.
`fixture.bend` consumes it with the distinct affine arrays in second-owner.Owner
and the historical affine resource owner. Gameplay sees abstract H and declared
OwnedRequest grants. A real ordinary Clause.write derives the registration access;
the same retained nominal descriptor validates each complete payload before Batch
acceptance. Access strings are observations, not the authority mechanism.

The eight complete reports cover two deferred spawns, two inserts, failed spawns,
a genuine handle from another factory-created world, late target disappearance,
validation rejection of both payloads, failed inserts and failed rejected requests.
Every report includes before/committed/barrier snapshots and full registered Local,
all payload/sentinel arrays, displaced owners, refusal errors and original/canonical
packets. Foreign and invalid requests add no command or reservation. Body failure
returns both accepted originals into explicit Local and never stages delivery.
Successful completion publishes closures through existing Batch.finish; payloads
remain invisible until actual W.barrier. Inserts retain displaced owners. A target
removed by an earlier pending command returns accepted payloads into explicit Mail
at the barrier. Existing commands/events are preserved and executed in FIFO order.
These are per-operation guarantees; no atomic all-command batch policy is invented.

Mail is the application-selected recovery callback already used in qualified
full-assembly-v1/application.bend:19–56. Its resource journal writes only value,
following that source's lines 75–90 and Resource.tx_replace displaced-owner behavior.
Returned/retired owners are outside the undo lens; no entire Mail resource undo can
replace them. Body failure happens before staging, so accepted packet recovery goes
directly to Local. The current World pending callback API cannot return an external
Local owner at a later barrier; the explicit Mail destination reuses the established
application contract, without assigning a global #41 activation recovery policy.

Canonical reservation/activation/order is the existing bundle-batch.bend and
commands.bend route: reservation consumes IDs on body failure, activation occurs at
barrier before spawn delivery, and Delivery.apply revalidates at delivery. Clock,
capacity and IDs are observed under those existing contracts. No new law, cleanup,
finalizer, #50 or #53 policy is introduced.

Source5 CPU5 shared-lock checks: fixture passes; undeclared/read-only/cross-schema/
affine duplication controls fail at actual capability bodies. Exact receipts and
transitive pins are in source-checks.json/source-closure.json. These are source/type
checks, not mathematical proofs or runtime qualification. Shared core promotion
and a reviewed independent full oracle/backend packet remain required; no #46
closure or performance claim is made.
