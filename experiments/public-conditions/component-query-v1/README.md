## Public API and preserved boundaries

binding and retain Required/Optional row selection. `with_component` and
`without_component` create membership predicates without projecting payloads.
`empty`, binary `pair`, predicate `both`, `constrain` and `map` reuse the existing
query algebra; arbitrary nesting replaces fixed tuple arities. Library
`declaration` lowers that composed selection to an ordinary described Check;
`each` is the confined readonly gameplay operation. A map transforms detached

using the existing Cap.Bundle shape. Nested composition is source-checked with
three leaves. Each reached Check validates its own declared resources before its
body. Required/Optional component selection determines matched rows and does not
create a whole-World missing-component error. The unchanged Cond.check, lazy

the new Component selection descriptions without a second metadata adapter.
