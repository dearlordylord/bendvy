# Checked-predicate authority controls

Three positive controls check the actual ordinary guard constructor, actual App
run wrapper, and generic faithful lift for an arbitrary affine old condition
owner. Ten intended refusals check a non-Bool predicate, missing read grant,
undeclared same-payload resource read, writing Counter through Input read-only
operations, cross-schema guard, abstract H escaping as World/Check.Frame/Handle,
and duplication of the actual App or lifted affine Array owner.

These checks exercise the canonical public operations and constructor signatures.
They do not claim raw provider/binding constructor secrecy or purity of trusted
admin callbacks. CHECKS.json records actual pinned CPU5/five-second invocations,
expected exits, intended diagnostics, raw hashes and unchanged pre/post joins to
SOURCE-PINS.json. Every negative reaches a type/quantity mismatch, not a parser,
timeout, foreign-code refusal or missing-file error.
