# Installed tool pins

`owned-tool-pins.py` extracts the reviewed relations guarded-v2 library-discovery pattern. It introduces no execution framework and does not migrate historical runners or receipts.

Import with `importlib.util`, then call `snapshot(execute=reviewed_execute, tools={name: path}, resource_roots=[...], ldd=..., taskset=..., cpu=..., env=complete_environment, skip_ldd=(script_names,), capture_mode=...)`. The injected callable is mandatory: `execute(argv, 5, env=...)` must enforce the reviewed owned-descendant cleanup contract. There is no fallback executor. Every discovery command is CPU-pinned through the explicitly pinned taskset binary. Configure installed Bend Base/effects and Clang resource roots explicitly; binaries, the ldd executable, resource members and resolved library bytes are pinned.

Capture mode must describe the actual executor: `split` retains separate raw bytes; `merged-stdout` retains the raw combined pipe and explicitly empty stderr. Neither mode manufactures split diagnostics. Results contain bytes and require deliberate encoding when publishing JSON. Nonzero status, supervisor failure, missing libraries, missing files, in-flight prerequisite/resource drift and verification drift refuse. `verify(previous, **same_configuration)` repeats bounded discovery and compares bytes, membership, raw logs and configuration. Caller-owned logs/receipts and source/config/target guards remain the caller's responsibility. Passing a callable cannot mechanically establish its supervision policy; review it independently.

Test command: `python3 scripts/test-owned-tool-pins.py`. Seven stdlib tests pass, including actual child stdout/stderr under the existing reviewed merged supervisor, observed cap argument5, CPU/environment forwarding, missing-library/nonzero refusal, byte/membership drift and mandatory executor. The actual-child test is not a five-second timeout duration measurement. No dependencies, ECS code, historical evidence or approved numeric policy changed.

Complete execution environment values are passed only to the executor. Receipts retain a deterministic SHA256 environment digest, never the full environment. This detects changes without publishing credentials; it is not a secrecy guarantee for low-entropy values. `ProbeFailure` carries raw `captures` (including prior successful probes) and current `probe` metadata on nonzero/supervisor/missing-library refusal; its message excludes child bytes. Encode bytes explicitly, e.g. base64, in external receipts. Tests preserve NUL/invalid UTF8 stdout and stderr on refusal.

Verification ignores only a trailing space-plus-hexadecimal load-address annotation `(0x...)` on recognized stdout library/loader/vdso lines; stderr and unrelated stdout text remain byte-exact. Raw snapshot bytes remain complete. Exact library paths, bytes, symbols, other text, status and configuration remain compared. Deterministic tests accept changed ASLR addresses while rejecting changed paths and warning/symbol text.
