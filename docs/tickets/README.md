# Local ticket records

These files preserve published scopes, acceptance conditions and subsequent
research notes. Filename sequence numbers are not necessarily GitHub issue
numbers. Use [ticket-issues.json](../ticket-issues.json) and the issue link in the
record to identify its governing issue.

GitHub issue state is authoritative. A recorded time allowance, process ID or
"next" instruction in an older ticket body is not renewed authorization. The
[parity index](../parity/README.md) routes remaining core work; the
[historical archive](../archive/README.md) preserves earlier plans and outcomes.
