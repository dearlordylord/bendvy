# Core task navigation

1. Select the governing GitHub issue from the requested task. Read the issue, its linked specification and acceptance evidence before implementation; use [SPEC](SPEC.md) and the [core map](reference/core-map.md) for the full-core scope.
2. For parity work, use the [parity index](parity/README.md) to locate the capability contract and ticket. Resolve current status from the issue and source-bound evidence rather than from this navigation page.
3. Follow the applicable [workflow branch](agent-workflow.md). Report each unmet acceptance gate explicitly; a bounded experiment does not complete the full capability.

Historical checkpoints and approval provenance are reached through the workflow when the task depends on them.
