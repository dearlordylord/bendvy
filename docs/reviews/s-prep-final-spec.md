# S-PREP final Spec/design review

Reviewed `ad7de65`, live issue #22, parent #21, SPEC, preparation ledger, candidate/contract proposals, structural receipts and focused/paired/check runners. Third authorized Astra consultation; read-only review except this report. No qualification loop executed.

**Verdict:** bounded candidate design is ready for experimental implementation; preparation supports an honest **blocked handoff**, conditional on final evidence reconciliation and Standards review. Evaluator/contract execution is **not ready**. No numerical product threshold is approved.

- **High — executable decision missing.** `paired-run.py:compare` validates sample completeness and computes intervals, but does not implement the proposed cohort-noise, TS-drift or keep tests. `COMPLETE_COMPARISON` emits a metric even when those proposed tests fail. Before acceptance, freeze protected decision code and adversarial controls enforcing qualification and both-cohort JS/Native bounds; distinguish measurable-but-rejected from qualified/keepable. Define the metric exactly: current code takes the median of two cohort medians, not the pooled fourteen-sample median. Define the denominator for the 10% cohort-difference test and apply it separately to repeated references and identical-source candidates, not improved candidate versus baseline.
- **High — execution/check contract incomplete.** Freeze checkout/base commits, full source/tool/check digests, exact commands/working directories/minimal environment, parser/decision paths, artifact root, editable/commit paths and packet cap. Materialization and every correctness check must bind to the same candidate digest; direct `owned-storage-run.py` reads its checkout rather than the supplied overlay. Set its temporary directory under the artifact root and retain diagnostics. Enforce the 3600-second cumulative deadline across builds, checks and descendants, including interruption/recovery. These are concrete engineering fields, not further budget questions.
- **Medium — connected coverage remains a gate.** The prototype establishes affine structural feasibility, not real token/Flag selectors, captures, writers or barrier rollback. Freeze executable integrated occupancy/order/shape/membership counterexamples before representation keeps; if their implementation changes protected checks, record the required contract transition. Retain both-schema main/E11/access/ownership gates. Finish the DenseHealth256 hook receipt; explicitly retain uncovered Sparse/Lifecycle and large-case/warmup blockers.

The revised trusted-constructor boundary, actual ALeaf/ANode reconstruction, successful placement/removal membership boundary and all-selection Main-absence rule are coherent. Full physical/shape preflight inside every measured query removes the unsupported sparse-complexity claim.

The proposed 10% JS improvement, 5% Native regression bound, repeated controls and bootstrap rule are reasonable conservative *experimental proposals*. Seven samples do not establish universal confidence; unresolved noise/quantization must stop keeps. Obtain explicit acceptance only after the frozen proposal and above repairs are reviewable. Parent performance and simulation remain blocked.
