## Existing mechanisms and their limits

- `experiments/rc1-query/api.bend:45,72` checks callbacks for arbitrary affine provider types, supplies fresh read/write operations and restores returned owners. Public concrete constructors do not identify the callback's abstract types. Reuse this capability pattern. Its scalar cell, String labels and tail-first lookup (`:105`) are not integrated identity, full payload or transaction semantics.
- `experiments/t06/core.bend:17,45,66` places actual owned arrays alongside a journal; each setter captures the old values, failure applies inverses, success publishes staged Data commands/events. Reuse inverse ownership/order, not its fixed-row fixture or Data-only command representation.
- `experiments/t07/streams.bend:5,37,66,69,72,76` supplies registration-aware cursor values, whole-batch trimming, reads and success/failure/skip helpers. It does not join the actual system registry, separate lifecycle positions or transactional dispatcher. `capacity_rows` repeatedly computes tail sizes; avoid quadratic trimming for public65536 cases by tracking counts or a linear pass without changing retained results.
- `experiments/s-capture/core.bend:47,50,85,88` demonstrates capture-adjacent transaction threading, but uses event-count positions and a barrier that clears String commands. Those shortcuts cannot implement the required clock or structural barrier. Reuse the returned-owner/once-only-closure pattern, preserving captures through failure.

## Smallest proposed composition

Begin with separate nominal Motion/Health payload records and an owned-list adapter. World owns actual Type Main/Aux/Ledger arrays, membership, identity and pending Type commands. A private concrete transaction owns World, reverse-ordered inverses and staged publications. Closed rank-2 callbacks receive only abstract transaction/provider handles and declared fresh operations; return the same opaque owner plus outcome and capture state. Concrete extraction/reinsertion stays inside the trusted adapter.

Capture each inverse inside the provided setter, including entity/component/array position and prior scalar; combine component and resource writes in the ordered transaction. Retain the actual array owners throughout. Full Data observations are outputs, never rollback substitutes. Rejected unqueued Type payloads return to the caller; accepted staged payloads transfer to transaction ownership and are discarded exactly once on failure. Committed pending owners transfer into live storage only at explicit barriers. Foreign commands return approved MissingEntity with receiver queue/rows/metadata unchanged; failure is not implicit.

Keep separate registered message and lifecycle boundaries, registration clock and invocation start clock. Read from saved boundaries; advance both completed boundaries on success, neither on failure, message only on skip. Preserve post-run message publication versus same-run change stamps. Removed/despawned observations must survive deletion, and E11 must retain exact public capacity, first failed read/same-instance retry, independent Fast and late registration behavior. Preflight all nested declared requirements before any callback or Audit effect; Audit and lexical captures remain outside ECS rollback.

No unavoidable Bend language blocker was found in these inspected mechanisms. Integrated performance remains mandatory and unmeasured here.
