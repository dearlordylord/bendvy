# Native1024 concrete owner handoff proposal

Decision: permit design review of ONE bounded source probe: a separate schema-concrete nominal handoff carrier whose owner field has the exact existing private MainSlot type. Do not implement yet. Preserve the original generic `HandoffRows<Schema,M:Type>` producer/recovery route and every public prefix/header/callback. Arbitrary affine M remains supported by that original route; the optimization is explicitly limited to the two already concrete private Motion/Health consumers. Raw owned Arrays remain Type. This is neither a Data-only component restriction nor a new universal generic representation.

## Bounded shape and route

Add distinct private Motion and Health rows datatypes, each with empty and node `{id,owner:CP.Prototype...MainSlot,rest:sameRows}`. Retain the nominal Slot field first; do not manually open/reassemble its fields unless a separately reviewed failure demands it. Add private Q producer/state/batch/return/recovery copies with only Schema/Main fixed to the concrete pair; keep Aux:Type, Flag:Data, Ledger:Type and Mode:Data general where the current frozen-template syntax permits. Cached-payload imports Base/types/uncached-payload/cache and does not import query, so its type import does not create the obvious query cycle.

In HA, select this carrier only from the two existing concrete handoff entries/drains. Preserve exact owner-preserving size>=capacity preflight and supported compiled-Array premise; failure and initial LedgerNone use the ORIGINAL generic query/fold before evacuation. Successful drain reconstructs the same namespace/id Handle and passes the nominal Slot to the ORIGINAL taken/invoke/returned callback family, preserving pending inverse pairs, marks, ledger/true-old semantics and all context.

Mid-drain LedgerNone restores FULL current+remaining concrete owners in ascending order and produces the same reverse-once Data IDs, then invokes the ORIGINAL cursor loop. Generic/nonidentity returned context must replace the incoming context completely; never reattach stale detached owners afterward. Original opaque callback authority and immutable retained Data remain unchanged. The existing exported hole-bearing Batch confinement limitation is not solved by a concrete carrier.

## Risks and first discriminating gate

Known node layout may become id+seven MotionSlot slots+tail=9 words, or id+nine HealthSlot slots+tail=11 words; heap class rounding can make either a16-word node. Current generic node occupies4 words plus a separately boxed owner. Eliminating a redirect or owner box can therefore increase Motion requested words. These are layout hypotheses, not measured allocation/time savings. Recursive tail sealing and Array.swap transport may remain. [Native blk_half](/tmp/bendvy-handoff-v8-motion-dense1024-build-r2/batch.c:1908) allocates/copies halves, so exposing concrete layout can also change Array movement costs. No additive prediction or Native speed claim is justified.

First gate: exact source/prefix/cache/type audit, checker15, emit30 and inspect actual C at the successful take. Require concrete owner slots and no new opaque Main constructor/seal at that edge; if C is effectively unchanged, stop this hypothesis. Then Clang120 and fresh Motion/Health1024 full65 versus actual TS within runtime5, followed by independently source-bound phase request/RFC/word and copy/Array attribution. Preserve failures; if extra node words/copies erase the mechanism, report negative before broadening.

Smallest semantic controls after a positive mechanism: bothschema one/two/empty selected rows; size-failure and LedgerNone before/mid-drain full recovery; allcells/raw-cache discrepancies/retained Main+Ledger Data after repeated writes; exact rollback/marks/Pair pendingflush; unchanged rank2 nonidentity fallback/full returned context; original generic arbitrary Type owner arrays and clone/schema/access negatives. Actual compiling current-owner drop, reversed drain/recovery, omitted restore/Pair flush, true-old and returned-context mutants must hit the new route. Fresh source29/extra/build receipts and original independent/literal oracles are mandatory. Oldv8 controls are comparator inputs, not new-route pass receipts.

The alternative of propagating `~M` instead of `-M` through generic helpers is not selected here: it is smaller but compiler global wildcard/hot facts can retain boxing from other live generic paths. This proposal changes the relevant constructor's declared field layout directly while preserving the generic path. No implementation, timing, dependency, proof/law, kernel/compiler/reference change or product adoption is delivered by this design note.
