## Required joins and decisions

1. **One integrated owner.** Connect schema providers, identity, variable membership, pending FIFO, resources, retained Type cells, lifecycle metadata and actual two readers. None of the existing files provides this combined world. Preserve every returned owner; do not expose a concrete writable world to closed systems.
2. **Transactional visibility.** Earlier system A remains committed. Failed B must discard its unpublished events/structural commands, restore declared recoverable writes and selected reader visibility, and preserve lexical capture. Connect marks/logs/cursors to the same finish path; observe rollback through readers rather than requiring raw generation rewind. Structural commands must actually apply at explicit flush; schedule execution must not implicitly flush.
3. **Allocation remains explicit.** T05 and S-LAYOUT begin IDs at 0; the approved Nat-model subject begins at 1. Pin the integration mapping rather than changing the approved subject. Public Factory constructors permit independent roots with equal counters, so trusted lineage is an experimental premise, not global authority. Capacity/no-reuse are bounded parameters. Failed-reservation consumption and subsequent reserve need fresh pinned TS execution: do not invent allocator rewind/reissue or normalize away escaped-handle aliasing. Any SPEC/reference divergence requires a recorded decision.
4. **Reversibility has a boundary.** Retaining an array owner plus scalar inverse supports the declared numeric writes. It does not recover an arbitrary consumed Type value. Keep destructive remove/despawn at the declared structural boundary, or retain a recoverable owner explicitly before allowing transactional destruction; no unrestricted restoration claim.
5. **Ordering and layout are separate.** R-C1 fixture order and T05 String labels do not establish ascending numeric queries under arbitrary physical permutation. S-LAYOUT sorted membership/map checks are concrete candidates; require identical logical traces for list/index adapters, with full declared payload observations. Its reported dense/JS regressions and untimed relocation do not pass integrated performance acceptance.
6. **Proof and executable evidence stay distinct.** The six approved Nat observation theorems do not prove these Type APIs or runtime refinement. The owned seventh endpoint and broader authority remain separate gates. #19 needs its own frozen declarations/trace contract, fresh TS/Native/JS observations, actual negative type controls and compiling semantic mutants before runtime acceptance; prior probe reports are supporting evidence only.

No runtime or proof source was changed for this inventory. References and Canonical Tower Defense were read-only and unchanged. Existing capability limits remain governed by each experiment's README and the linked ticket.
