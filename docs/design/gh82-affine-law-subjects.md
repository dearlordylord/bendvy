# GH82 affine law subjects — draft, not approved or proved

These subjects concern actual `Type` owners. The five previously approved reusable-Data execution laws authorize none of them. No Python model, numeric inventory equality, sampled snapshot, or Data-only theorem establishes them.

| Candidate | Exact production subject and owner carrier | Required behavior and limits |
| --- | --- | --- |
| cut_refusal_owner | `chunk-partition.cut(S,C,column,left,right) -> Cut<S,C>`, with arbitrary `C:Type`, actual `Col.Column<S,C>` | Malformed complete tree, duplicate/out-of-range domain, or overlap must return `Refused{column,reason}` carrying the exact original column, all payloads and stamps, before scatter. Refusal precedence must match `cut_valid`. |
| cut_join_owner_roundtrip | `cut` followed by `join(S,C,join,remainder,left,right) -> Joined<S,C>` on the actual returned owners | An unchanged successful partition rejoins the original complete owner tree and stamps. Every displaced absent cell must also be accounted for; success does not mean the displaced list is empty. Premise: a well-shaped original column and validated disjoint complete domains. |
| join_refusal_inventory | `join` with actual `JoinOwner<S,C>`, `Column<S,C>`, and two `Slice<S,C>` values | Invalid shape or changed/duplicate/missing returned cell offsets returns `JoinRefused{remainder,left,right,join,ChangedInventory{}}` with every supplied actual owner retained. No hypothetical predecessor owners are substituted. |
| join_displaced_owner | `replace` / `put_all` / `join`, actual `Cell<C>` and `List<&1,Cell<C>>` | Every unexpected occupied destination is returned in displaced inventory with its payload and prior stamp; every inserted owner reaches its requested validated offset exactly once. This must cover arbitrary affine C rather than owner counts. |
| unsupported_preparation_owner | `execution-query-preparation.inspect` / `prepare`, actual `W.World<S,L.columns(S,full),WR,E>` and `Sys.Owner<...>` | Unsupported closed compilation returns actual unchanged World and owner before registration, clock entry or body. Arbitrary affine Local and resource owners are retained. This is not merely `compilation_supported == False`. |
| admitted_authority_binding | `Preparation.Prepared{world,Binding{prepared,evidence}}` and `invoke_whole` / `invoke_sparse` | Invocation uses the same closed Program, full layout, namespace, full handles/generations and admitted grant upper bounds. Changed evidence/storage refuses while retaining actual scope, Prepared/owner and evidence. Fresh predicate matches cannot widen grants or silently truncate an invalid request. |

The intended proof statements must use an owner-sensitive consuming relation or a sound equality principle that actually admits arbitrary affine values. Writing `{f(column) == g(column)}` duplicates an affine `column`; adding `+` would require Data and destroy the claim. No such replacement is proposed. The next law-drafting step is to establish the exact legal Bend proposition/continuation encoding for the actual affine carriers, then back-translate its premises and guarantees for approval before proof work. These are precise subjects and obligations, not filled laws or a secrecy theorem about public raw constructors.

Bevy behavior references already pinned in the foundation README motivate With/Without/optional membership and conflicting mutable access. Affine scatter/rejoin, explicit displaced inventories and Prepared preservation are Bend-specific contracts; a Bevy reference cannot prove them.
