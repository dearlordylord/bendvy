# Ordinary linked despawn

An ordinary canonical command Buffer.Despawn now uses the shared relation cleanup
control and engine when the actual full resource schema contains protected graph
or lifetime-scope resources. The historical direct path remains for schemas with
neither resource kind. There is one authored queue and one ordinary executor.
No Scope.Assign or Scope.Cleanup command substitutes for ordinary despawn.

The existing Control selects the behavior by each descriptor's actual kind.
Hierarchy inverse descendants are removed postorder. Ordinary incoming sources
are unrelated and survive. Every descriptor removes the departing entity's
outgoing relation before component disposal. The existing canonical disposal
path returns the full affine Removed bundle, appends lifecycle notices and
releases the same actual allocator identity. The original requested handle,
including namespace and generation, remains in the outer LinkedDespawn receipt.
Its nested receipts retain every actual removed owner, relation operation and
scope result. Incomplete progress retains actual frames and partial inventories.

A closed AfterDespawn action replaces the cleanup state's implicit scope route.
KeepMembership requires no fabricated route. ForgetMembership carries actual
already-proved scope routes. The existing scope-cleanup adapter supplies its
selected route; ordinary linked cleanup supplies all accepted scope routes and
forgets membership only after an actual Despawned receipt. Both adapters execute
the same Control and Engine. The exact Nat structural allowance, initial drive1,
Complete/zero-owner short-circuits and frame order remain unchanged. Redundant
step/resume template helper layers were removed without erasing the actual State
or the closed step witness.

## Schema provisioning and admission

Admission verifies structural entity permission, actual retained Context,
namespace and full-generation allocator liveness. Before the first mutation it
checks that the framework catalogue covers every protected graph and scope
leaf. The typed graph observer verifies every graph Store namespace. A read-only
scope Inspect request verifies each actual scope Store namespace without changing
membership, cache or stamp. Every branch uses lexical payload/view/actual-policy
proofs; policy flags never supply a type.

The closed `execution-schema-provisioning.Blueprint<S,resources,Seed>` constructs
owners and framework adapters together. Graph and scope constructors retain exact
payload/view/policy evidence. Pair composition consumes each runtime affine seed
once and composes resource-only dispatch, snapshot, namespace preflight and
retention adapters. It carries no actual World, Reader or runtime seed. Route
lists are passive coverage metadata. Whole Schema validation checks unique names
before creation; child validity proofs are never promoted to full-root proofs.

`Setup.create_provisioned` consumes the actual Factory, builds all stores with its
next namespace, calls Schema.create once and retains the SAME Blueprint index.
The new `execution-provisioned-root-application.run_bound_serial` entry retains
that index with the original Data Context. Before clocks, guards or publication,
it checks Context namespace, every actual protected Store namespace and complete
schema coverage, returning every owner unchanged on refusal. It delegates to the
existing DeferredSchedule and Root callbacks, with no new executor or queue.

The actual Compilation still determines gameplay permissions and metadata.
`Permission.Selection` keeps separate gameplay and framework cleanup adapters.
Authored Relation and LifetimeScope entries use only gameplay adapters. Ordinary
Despawn alone selects schema cleanup adapters. Root automatically composes the
same Blueprint's retention after overall Finished, preserving Bound preflight;
Stopped/Invalid pass through unchanged. The historical raw entry remains and
refuses missing protected cleanup authority rather than guessing payload types.
Other existing application entry shapes have not been migrated automatically.

The passive command inspector recursively reconstructs the same actual nested
receipt owners and returns detached Data facts. Existing terminal formatters
recognize the richer receipt. The ordinary linked consumer renders the actual
removed payloads and operation/error values in full.

## Actual ordinary consumer

relation Scene with affine component owners and a second Ordinary descriptor.
Its actual Factory creates the namespace; reserve/activate issue all three live
handles through the same allocator. The ordinary author enqueues inserts of
owners11/22/33, a hierarchy reparent, an Ordinary link and a cycle attempt. A second
registered command author requests only EntityGrant, leaving relation/scope grants
unused, and enqueues two ordinary Despawn commands. The existing dependency edge
orders the authors. Handled BodyErrors retain and publish their actual queues.

full handle was refused. Pending count and paused-frame count were both zero.

sequence0/olderThrough0; both report maintenance tick0:4 with nextReader1 retained.

workspace (ordinary entry session55940, exit0). This finite observation is not a
