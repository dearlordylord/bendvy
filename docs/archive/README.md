# Historical archive

These records preserve design decisions, rejected alternatives, source-backed
insights and acceptance evidence. Their budgets, PIDs, status snapshots and
proposed next steps are historical. Use the [current documentation index](../README.md)
and governing issue for present work.

The machine-readable [provenance manifest](provenance.json) records original
paths, recovered source commits, original hashes and archived hashes. Relocation
changes link targets and adds this historical notice; original prose is retained.
