# Historical archive

Historical plans, reviews and run receipts remain in Git history. Links below
select the frozen records. The local TS inventory remains available because
current parity documentation uses it. Their budgets, PIDs, status snapshots and
proposed next steps are historical. Use the [current documentation index](../README.md)
and governing issue for present work.

The machine-readable [provenance manifest](https://github.com/dearlordylord/bendvy/blob/b50440d867dbeafbcdd475ac8ee1dd73b48210bd/docs/archive/provenance.json) records original
paths, recovered source commits, original hashes and archived hashes. Relocation
changes link targets and adds this historical notice; original prose is retained.
