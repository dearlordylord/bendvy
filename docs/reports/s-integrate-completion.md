Native substantially faster than bevy-ts and JS at least comparable remain
mandatory product goals. These results reject current production adoption.
Adverse ratios, incomplete cases, clock quantization, descriptor-construction
asymmetry and process-wide memory scope cannot become acceptance by closing
research. No new universal law or proof was approved or written in this task.

## Concrete return path

[S-PERF #20](https://github.com/dearlordylord/bendvy/issues/20) implements and
evaluates one experimental owned indexed adapter, with a design freeze first.
It retains full trace/access/mutation gates, mapping/relocation controls, all five
workloads, aligned timing callback construction, corrected RSS and preserved
failures. Add the quiet FailedTxn adapter without removing any declared fields,
queries, lookups, reader identity, consumed reservations or transaction boundary;
validate it against both full diagnostics before timing. Stable checking/builds
under existing limits and explicit peak occupancy measurements are return gates.
A positive microbenchmark does not adopt a production layout.

Generic repeated-label binding, general Local/destructive Type recovery, root
confinement, reuse/exhaustion, broader schemas/provisioning and parallel execution
retain full-core #1 follow-ups. Simulation and the separate Tower Defense copy
remain downstream packages; `/workspace/typescript/jev` was not modified.
