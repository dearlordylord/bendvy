# Blind ECS API audit — outcome

**#25 research delivered; requested full ECS simulation remains blocked.**
The independent consumer can use structural commands and generic read queries
while preserving affine owners. The supplied application boundary does not yet
register arbitrary caller-authored systems or expose independently declared
component families beyond its bounded slot schema. Optimization is paused;
performance acceptance and production API selection remain open.

## Method and correction

A fresh worker with no inherited conversation received a history-free, read-only
copy of exact29 modules (closurea4672d11), installed Bend guide/Base and pinned
Rust Bevy, bevy-ts and Bend compiler/runtime source. It did not receive timings,
optimization rationale, earlier reviewer findings or suggested engine adapters.
Isolation is protocol-based on a shared filesystem; it is not a security sandbox.
[Provenance and source archive](../../experiments/api-blind-audit/README.md)
record inputs, first impressions, original verdict and original44 artifact hashes.

Its initial payload-query failure was a **client error**: ordinary erased `-get`
is not a compile-time template `~get`. Root independently changed only the four
observer binders to~P/~U/~get/~ag, preserving every library byte. Installed Bend
and compiledJS both returned the exact value3. The agent then verified this
correction, an actual Array-owning Type payload and an actual public setter
confinement pair in new files. The original [blind report](../../experiments/api-blind-audit/blind-evidence/report.md)
is preserved, not silently rewritten; its getter-blocker conclusion is withdrawn
by the separate [assisted report](../../experiments/api-blind-audit/assisted-evidence/after-assistance.md).
No optimization history was disclosed during that language assistance.

## ECS and Bend interpretation

Pinned Bevy independently authors functions using Query/Res/Commands and
registers them as systems. Pinned bevy-ts independently authors callbacks with
declared query/resource/command access. Source citations and illustrative
reference code are in the two consumer reports; no Rust sample execution is
claimed. Repeating template arguments and threading affine owners are legitimate
Bend costs. Selecting an engine-authored BodyKind in place of one's own gameplay
function is a missing public seam, not a Bend requirement.

A compound payload may be an implementation representation. It does not by
itself provide independently selectable component membership, lifecycle and
capability declarations. The finding is about the supplied public interface,
not a proof that Bend cannot express more components or that past changes caused
a regression. Existing structural/query primitives are useful building blocks;
calling them production ECS application acceptance would overstate this audit.
