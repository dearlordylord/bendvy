# Evidence reports

Reports qualify the source, workload and receipts they name. They are not a live
project-status database. Resolve current completion from the governing GitHub
issue and [parity index](../parity/README.md).

| Evidence area | Entry points |
| --- | --- |
| Joined source and regression | [Integrated core regression](core-integrated-regression.md), [feature/world batch](feature-world-batch-regression.md), [creator regression](world-io-regression.md) |
| Query and declarations | [Query composition](query-composition.md), [public query contract](public-query-contract.md), [user-system API](user-system-api.md) |
| Schedules and ownership | [Schedules](public-schedules.md), [nested provisioning](nested-provision-completion.md), [schedule readers](schedule-readers-completion.md), [Local](public-local-owner.md) |
| Streams and lifecycle | [Event readers](public-event-readers.md), [removal readers](public-removal-readers.md) |
| Typed composition | [Schema fragments](schema-fragments-completion.md), [features](features-completion.md), [component states](component-state-completion.md) |
| Recent applications | [Relations](relations-application-initial.md), [machines](machines-application-initial.md); initial evidence is not full-issue acceptance |
| Regression baseline | [Performance regression contract delivery](performance-regression.md), [historical parity receipt](parity-current-regression.md) |
| Optimization mechanisms and rejected candidates | [Historical performance investigations](../archive/README.md#performance-investigations) |

Completion reports, mutation evidence and negative findings are retained. A
historical review may explain a decision without renewing acceptance for changed
source. Historical records recovered from Git have explicit provenance in the
[archive](../archive/README.md#recovered-reviews).
