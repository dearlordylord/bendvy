## What the programs actually do

| Product technique | Source and observed evidence | Transfer to Bendvy |
|---|---|---|
| Voxel spatial subdivision reduces candidates before pixel work | `Projected.filter` uses bounds; `Tiles.build` makes four smaller candidate lists. [Code](https://github.com/aivv73/bend-voxel/blob/fade41f9b47e21d56f09e0edbfde714fad0395df/render.bend#L309-L332) | Precompute query membership/indexes at the correct mutation boundary; avoid rescanning every component for every entity. Preserve ownership, schema and access checks. |
| Voxel retains scene lighting across camera changes | `RenderScene.build` constructs lighting; `reproject` extracts the existing cache and passes it into projection. [Code](https://github.com/aivv73/bend-voxel/blob/fade41f9b47e21d56f09e0edbfde714fad0395df/render.bend#L757-L768) | Distinguish structural query/cache invalidation from ordinary component writes. A retained cache must not become authority or preserve stale values. |
| Voxel separates data subdivision from runtime parallel decomposition | `Tiles.image` has a sequential depth-zero path and an explicit four-way parallel let at positive depth. [Code](https://github.com/aivv73/bend-voxel/blob/fade41f9b47e21d56f09e0edbfde714fad0395df/render.bend#L978-L999) | Parallelism needs enough independent work per fork. This does not justify changing the accepted one-worker native comparison or parallelizing affine world owners without a valid split. |
| TOON avoids constructing data that no consumer uses | Encode without stats validates UTF-8 without constructing decoded text. Reported **18.3% fewer instructions**, not elapsed-time evidence. [Experiment](https://github.com/Dicklesworthstone/toon_bend/blob/b74a789a8cbd73c54da82e129337240d63dc5a29/perf/EXPERIMENTS.md#L885-L922) | Remove dead intermediate carriers only when no callback, rollback, marks, ownership or trace observes them. |
| TOON avoids repeated copying of whole inputs | `chunks.all` retains the newest chunk as the final tail; the first file read is 16 MiB. Reported **11.6% fewer instructions** against the preceding optimized build. [Code](https://github.com/Dicklesworthstone/toon_bend/blob/b74a789a8cbd73c54da82e129337240d63dc5a29/port/main.bend#L27-L92), [experiment](https://github.com/Dicklesworthstone/toon_bend/blob/b74a789a8cbd73c54da82e129337240d63dc5a29/perf/EXPERIMENTS.md#L924-L955) | Inspect owner/world reconstruction and list concatenation in generated code. Keep a value affine and move it once where possible. This is not permission to delete journal entries. |
| TOON changes traversal direction rather than adding a wrapper | Reversed decoded text is scanned directly, building each line forward once rather than copying it three times. Reported **24.3% fewer instructions**. [Experiment](https://github.com/Dicklesworthstone/toon_bend/blob/b74a789a8cbd73c54da82e129337240d63dc5a29/perf/EXPERIMENTS.md#L1056-L1091) | Prefer removal of an actual full traversal over tiny getter/writer dispatch reductions. Validate exact observable ordering. |
| TOON uses a bounded small-case algorithm before an index | Small JSON objects scan their own chain; the ninth unique member constructs the hash trie once. Reported **12.5% fewer instructions** on flights, 3.2% on gsoc and +0.007% on canada. [Code](https://github.com/Dicklesworthstone/toon_bend/blob/b74a789a8cbd73c54da82e129337240d63dc5a29/port/json.bend#L350-L399), [experiment](https://github.com/Dicklesworthstone/toon_bend/blob/b74a789a8cbd73c54da82e129337240d63dc5a29/perf/EXPERIMENTS.md#L1240-L1269) | Consider bounded small-query specialization with a general indexed fallback. Crossover must be measured across sizes; do not turn the fixed dense fixture into the API. |
| TOON enables compiler borrowing by changing an actual recognizer | A state-only numeric recognizer avoids constructing a lexer record per character, stops at the reject sink, and permits borrowing of strings. Reported **13.5% fewer instructions**. [Experiment](https://github.com/Dicklesworthstone/toon_bend/blob/b74a789a8cbd73c54da82e129337240d63dc5a29/perf/EXPERIMENTS.md#L1093-L1127) | Inspect emitted `keep`, sealing and shared destructuring. Do not assume `+`, a template or a helper alone proves a borrow or removes an allocation for arbitrary affine `Type` components. |

## Where the measured cost sits

TOON's committed profile uses Cachegrind instruction counts with **explicit `--threads 1`**, not timing. Reference counting/teardown (`term_drop`, `rfc_wrap`, `span_fade`) account for **36.8–49.1%** of total instructions in the listed nontrivial cases; runtime including those costs is **61.0–77.1%**. The profile's earlier default-thread attribution was corrected. [Profile and provenance](https://github.com/Dicklesworthstone/toon_bend/blob/b74a789a8cbd73c54da82e129337240d63dc5a29/perf/COUNTED-PROFILE.md#L20-L84), [raw paired counts](https://github.com/Dicklesworthstone/toon_bend/blob/b74a789a8cbd73c54da82e129337240d63dc5a29/perf/evidence/COUNTED-PROFILE.825e44de.counts.jsonl#L1-L14).

This supports a hypothesis about ownership/copy overhead, not a conclusion about Bendvy's bottleneck. The same profile's emitted-code audit reports 2 borrowing sites against 2,548 sealing sites in program segments; whole-file textual counts include runtime definitions and must not be mixed with segment counts. [Audit interpretation](https://github.com/Dicklesworthstone/toon_bend/blob/b74a789a8cbd73c54da82e129337240d63dc5a29/perf/COUNTED-PROFILE.md#L119-L143).

Voxel's historical daylight benchmark includes native presentation and four edit/reset cache rebuilds: 48 measured frames, eight warmups, two repetitions, reversed order. GPU tile/fork depth **5/5 → 6/6: 174.281 → 90.229 ms/frame**; depth7 gives91.042. CPU one-worker **127.688 → 113.854**; six workers62.604→59.479; twelve54.042→51.302. All sixteen image exports at tested depths4–6 remain byte-identical. These are author-reported renderer results, not ECS throughput or JS/native comparison; native display refresh can cap earlier frame results. [Results and limits](https://github.com/aivv73/bend-voxel/blob/fade41f9b47e21d56f09e0edbfde714fad0395df/docs/verification.md#L124-L173).

FFI is not the demonstrated TOON speed lever: its one custom effect imports matching C/JS implementations to open the actual stdin descriptor correctly. [Boundary](https://github.com/Dicklesworthstone/toon_bend/blob/b74a789a8cbd73c54da82e129337240d63dc5a29/port/main.bend#L95-L114). The inspected current voxel pin's rendering decomposition is Bend source. Neither pin demonstrates our required affine-Type ECS JS parity and native2× target.

## Negative evidence worth retaining

- Reducing reversals did not produce a qualified wall improvement: TOON EXP-010 was reverted; reported ratios1.007×/1.006× had CV8–21%. [Record](https://github.com/Dicklesworthstone/toon_bend/blob/b74a789a8cbd73c54da82e129337240d63dc5a29/perf/EXPERIMENTS.md#L392-L422).
- UTF-8/parser fusion reduced native instruction counts but created an invalid Unicode scalar on JS/interpreter; EXP-032 was reverted. Native success and checked laws did not establish cross-runtime correctness. [Record](https://github.com/Dicklesworthstone/toon_bend/blob/b74a789a8cbd73c54da82e129337240d63dc5a29/perf/EXPERIMENTS.md#L1338-L1364).
- An apparently removable expansion pass was not a pass at all; the stronger proposal discarded load-bearing unfinished objects. EXP-033 was withdrawn before implementation. Read the actual callee before estimating a pass-removal ceiling. [Correction](https://github.com/Dicklesworthstone/toon_bend/blob/b74a789a8cbd73c54da82e129337240d63dc5a29/perf/EXPERIMENTS.md#L1366-L1485).

## Recommended next Bendvy investigation

1. Attribute the current exact candidate's generated JS/C: opaque callback invocations, owner extraction/reconstruction, full-list/tree walks, allocation, sealing/keep/shared destructuring, journal and mark construction. Compare equivalent work; preserve all full-state/effect gates.
2. Select a lever that removes quantified work on the hot path: a traversal, repeated lookup, redundant copy or sharing lifetime. Distinguish compiler-lowering hypotheses from measured effects. Keep compiler/kernel changes out of an application experiment.
3. Recheck both backends and negative controls before timing. Retain true physical old values, every mark, inverse order, abstract-handle confinement and arbitrary affine `Type` components.
4. Qualify wall-clock comparisons against the pinned bevy-ts at JS≤1 and native≤0.5. Instruction counts can prioritize hypotheses but cannot satisfy those targets. Parallelism is a separate follow-up rather than a shortcut around the one-worker baseline.
