# Issue tracker

GitHub Issues in `dearlordylord/bendvy` are authoritative. Use `gh issue view
<number> --repo dearlordylord/bendvy --json title,body,state` to read a ticket.
Local ticket copies and mappings are under `docs/tickets/` and
`docs/ticket-issues.json`; reconcile them with the live issue before delivery.

The full-core parent is #1. Execution-ready work uses `ready-for-agent`.
Follow AGENTS.md for direct delivery, approval gates and research outcomes.
PRs are not an additional request surface.
