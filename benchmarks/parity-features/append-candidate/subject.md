# Proposed append equivalence subject (unapproved)

For every Data event type E and finite left/right lists, Nil-left returns the right list; Nil-right returns the left list; two nonempty inputs use the original reverse+append_loop. The result equals the original concatenation in complete payload sequence, multiplicity and order. No callback, owner operation or cursor changes. This is a proposed subject, not an approved law or proof.

Finite falsification compares complete actual old/candidate outputs, including both empty, empty on each side, repeated values and several lengths. A reached wrong-right-empty-order mutant reverses a nonempty left list and must be detected on JS/Native. The complete actual reader workload remains mandatory before timing. No live-core change or universal-refinement/performance claim follows from these finite controls.
