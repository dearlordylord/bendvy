# Current execution evidence

The generalized Root migration was emitted with the pinned Bend compiler and
run as the actual JavaScript product API. Setup passively observed 523 bodies.
After 180 movement frames, the application reported tick 180, health 5, 77 kills,
525 enemies, 14 projectile/effect rows and 550 total bodies. All six original
Body kinds were present. Complete initial and final JSON observations were saved
for the migration delivery.

This finite run demonstrates the reached application path. It does not establish
universal correctness, native parallel qualification or new approved laws.

The existing `test.mjs`, `host-smoke.mjs`, `browser-smoke.mjs` and `check.sh` remain
preserved. Their synchronous Packet and old World API assumptions predate the
replacement. They were not invoked as validation of the new runtime. The existing
Bend scenarios retain their combat inputs and now return the actual application's
compiled IO computations.
