# Frozen user simulation contract

Normative finite external checkpoints: `expected.json`, generated by actual
pinned bevy-ts, before Bend implementation. `reference.mjs` authors systems using
public descriptors/schema/query/system/runtime/command APIs; it does not import
Bend code or engine journals. Replay: `timeout 5s node reference.mjs --verify`.

Three independently selected component families carry complete arrays:
Position `{x, trail}`, Velocity `{dx, history}`, Health `{hp, history}`;
optional Armor `{value}` and Tag `{}` have independent membership. TS arrays
represent logical full contents of Bend-owned Array payloads, not affine proof.
Dt is a scalar resource. IDs are normalized public EntityId.value, ascending.
Absent components are explicitly null; optional reads narrow on public `present`.

23 checkpoints cover empty, queued setup, visible setup; three movement/damage
iterations; failed write/resource/event/spawn rollback and unchanged barrier;
same callback/runtime retry; insertion/removal/despawn before and after explicit
barriers; independent with-Tag/without-Velocity filtering and read-only event
observation. Movement adds Velocity.dx*Dt. Damage subtracts 2-Armor.value, emits
Hit with full id/amount/hp, emits Death and queues despawn when hp<=0. All arrays
must remain complete and unchanged. Each observation consumes this reader's
new events; absence of failed publication is checked on the next observation.

Failed system sets all moving x to999, Dt9, emits Hit999, queues ghost Position999
then returns Rejected. Earlier successful movement stays committed. Retry on the
same runtime and same callback succeeds with Dt1; it does not replay movement.

Queue/publication evidence is external: visible membership and a subsequent
barrier test pending command effects; no private queue inspection. The failed
system's staged ghost never appears after barrier. More detailed public pending
queue APIs are not required by this oracle.

## Intentional foreign-world divergence

`foreign-collision-reference` observes a handle from a second runtime with the
same schema and numeric ID1 resolving successfully to local Position x6. TS root
brands are schema-bound, not runtime nonces. This observation is NOT Bend parity:
Bend must return MissingEntity for a foreign handle and leave its command queue
unchanged, as separately approved. This checkpoint is a reference difference;
Bend tests must check the approved result and post-barrier unchanged membership,
not silently substitute successful reference lookup. Foreign-world commands are
not executed in this TS oracle.

Finite application observations do not establish universal refinement, affine
safety, negative compilation controls, performance or production adoption.
